# 权限目录 · 功能拆解

[PRD](00-prd.md) · [页面](01-pages.md) · [故事](03-user-stories.md)

| 功能 ID | 页面 | 规则 | 失败反馈 |
| --- | --- | --- | --- |
| PC-F01 目录浏览 | PC-P01、PC-P02 | 服务端为权限编码、工具集合、CRUD 分类和接口路由的唯一来源，界面只选择真实动作。 | 无匹配、目录加载失败、管理员专属。 |
| PC-F02 范围选择 | PC-P02 | 授权点和范围同一条保存。生产与预发命名空间授权必须校验业务线归属，集群能力使用实例，平台管理对象使用全局。 | 无权限范围以及目录变化失败关闭。 |
| PC-F03 动作裁决 | 全局 | 使用稳定编码和处理器中的真实操作。复用路由按动作分流。列表、汇总、知识引用分别执行数据范围校验。 | 未登录 401。无权 403。不可见的对象与不存在采用相同响应。 |
| PC-F04 角色保存与审计 | PC-P03 | 乐观并发核对、批量勾选与影响统计、操作审计。保护已有角色与用户组关系。 | 版本冲突、旧客户端覆盖新授权、引用中删除均拒绝。 |
| PC-F05 兼容与解释 | PC-P04 | 角色来源取并集，旧角色诊断范围映射现有五种能力。既有显式策略继续按原路径判定。 | 环境或业务线变化后立即收回失效范围。 |
| PC-F06 业务状态 | PC-P01、PC-P02 | 发布、模型请求、Wiki 同步、平台高危操作在功能授权之后仍受各自约束。 | 保留状态冲突、参数错误、审核和可诊断的依赖失败反馈。 |
