# 权限目录 · 测试用例

[开发任务](04-development-tasks.md) · [PRD](00-prd.md)

| 测试 ID | 任务 | 前置与动作 | 预期 |
| --- | --- | --- | --- |
| PC-UT01 | PC-T01 | 遍历目录、标识、动作分类和范围类型。 | 独立动作编码唯一，CRUD 和风险字段齐全。 |
| PC-UT02 | PC-T02、PC-T03 | 同账号测试环境有写，生产环境有读；在两个实例调用相同动作。 | 测试写允许，生产写拒绝；未授予的业务动作不得继承。 |
| PC-UT03 | PC-T02 | 权限有直接与组来源，依次撤销来源；另以旧角色登录查询历史诊断。 | 来源准确，最后一条撤销后拒绝。旧范围继续有效。 |
| PC-UT04 | PC-T04 | 仅授予草稿编辑，同路径调用 publish／discard；用无版本权限访问历史知识。 | 审核与撤回动作不通过，版本内容不泄露。 |
| PC-UT05 | PC-T04 | 来源权限被撤销后同步，知识撤回后问答；本人凭据写操作并发存在性变化。 | 同步／引用失败关闭；绑定与更换遵守各自动作。 |
| PC-UT06 | PC-T05 | 分别授予角色列表、组列表、审计读；访问共享接口与管理写。 | 返回有权字段，管理写请求拒绝。 |
| PC-UT07 | PC-T02、PC-T06 | 两个管理员同时编辑同一角色，第二人持旧快照提交。 | 版本冲突，保留首个提交和编辑输入。 |
| PC-UT08 | PC-T06、PC-T07 | 浏览器点击权限目录、选择模块、搜索、勾选、设置数据范围、预览并保存。 | 目录可操作，角色接口收到与预览一致的授权。 |
| PC-UT09 | PC-T05、PC-T07 | 无权用户伪造 action、方法、请求对象范围；访问原有 LDAP 和审计。 | 未登记变更拒绝，存量管理员路径可用。 |

## 管理员组与权限点勾选验收用例

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| PC-TC21 | 超级管理员新建空组，勾选系统管理员并核对保存 | 显示当前成员 0 人，审计可定位；后续加入的 LDAP 员工登录获得系统管理员 |
| PC-TC22 | 已有组包含普通员工、直授管理员、其他组管理员 | 仅原普通员工重新登录才能获得权限，另外两人的会话仍有效；账号详情显示全部来源 |
| PC-TC23 | 撤销用户组管理员角色，随后重新授予 | 仅失去最后来源的账号会话失效，永久停用和待改密按原限制处理 |
| PC-TC24 | 普通管理员尝试新建、编辑、批量改角色、加入／移出管理员组，或操作继承管理员的账号 | 每条越权写入失败，批量正常条目仍可按原规则处理 |
| PC-TC25 | 获取影响预览后修改组成员，提交旧预览 | 返回冲突，权限、目标会话和组关系无部分写入。重新预览后可提交 |
| PC-TC26 | 勾选一个权限，点击名称查看详情 | 勾选持续，详情可独立切换；键盘可选 |
| PC-TC27 | 筛选部分权限后批量勾选，切换模块再返回 | 仅影响当前可见、可配置权限；隐藏项保留，部分选择显示半选 |
| PC-TC28 | 将同一动作添加到测试范围两次和生产范围一次 | 清单两条，敏感新增在确认页标记，只有确认保存后生效 |
| PC-TC29 | 勾选后直接尝试预览保存，或取消确认 | 未添加的勾选提示先加入清单，保存失败或取消时既有授权继续生效 |
