# 权限目录 · 用户故事

[功能](02-features.md) · [任务](04-development-tasks.md) · [测试](05-unit-test-cases.md)

| 故事 ID | 功能 | 用户目标 | 可观察验收 |
| --- | --- | --- | --- |
| PC-US01 | PC-F01 | 管理员从业务按钮查到对应接口。 | 搜索发布编码，只高亮候选发布，详情显示共享 POST 的 action。 |
| PC-US02 | PC-F02、PC-F04 | 值班负责人允许测试写复核、生产只读。 | 预览同时显示测试写、生产读的权限和范围。生产写拒绝。 |
| PC-US03 | PC-F03、PC-F06 | 知识作者可以写草稿，发布者保留独立权限。 | 仅有保存权限时，发布动作拒绝。生产发布仍需第二位有权管理员。 |
| PC-US04 | PC-F05 | 管理员解释某用户为何拥有权限。 | 用户详情显示直接与组继承两条来源。撤销一条仍保持另一条生效。 |
| PC-US05 | PC-F03 | 审计员读取审计，无权变更保留策略。 | 审计可授权查询，保留策略仍受管理身份和独立能力约束。 |
| PC-US06 | PC-F04、PC-F05 | 升级期间继续使用旧角色和 LDAP。 | 旧角色保留原有诊断读取范围，旧管理员和 LDAP 流程继续工作。 |
