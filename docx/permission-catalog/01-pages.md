# 权限目录 · 页面拆解

[PRD](00-prd.md) · [交互原型](prototype.html) · [功能](02-features.md)

| 页面 ID | 入口和角色 | 页面元素与操作 | 状态 |
| --- | --- | --- | --- |
| PC-P01 权限目录 | 系统管理 → 权限配置 → 权限目录。系统管理员和获目录查询许可的账号 | 诊断控制台、运维知识库、资源管理、系统管理四个独立页签、工具集合、搜索、风险筛选、增删改查矩阵。选中一个动作后显示编码、方法、路径、分流条件、风险和适用范围。 | 无匹配显示空态。矩阵中未提供的权限显示「—」，管理员专属动作显示来源原因。 |
| PC-P02 角色编辑 | 角色配置 → 新建或编辑。系统管理员 | 复用目录，单独选接口动作，指定环境、实例、业务线、命名空间或本身适用的范围。支持筛选、批量选择一个集合的常规查询。角色已有的诊断范围继续可见。 | 分开筛选待加入清单和已配置权限，接口详情显示该角色已配置的各个范围。保留既有目录联动，目录加载失败时提示重试。提交前检测版本。 |
| PC-P03 变更预览与结果 | 角色编辑 → 预览。当前编辑人 | 比对新增、撤销、权限范围、直接引用、组引用和去重人数。确认保存后返回角色列表，可在操作审计核对本次变更。 | 过时版本返回冲突且保留草稿。预览和撤销均允许返回编辑。 |
| PC-P04 生效权限 | 用户管理 → 用户详情 → 生效权限。系统管理员 | 按动作和范围显示直接或组继承的来源。仍可从用户详情查询审计。 | 同一条授予的多条来源合并。没有匹配时显示空态。 |

窄屏下矩阵水平滚动，接口详情移到矩阵下方。交互原型使用示例账号、范围及审计记录。
