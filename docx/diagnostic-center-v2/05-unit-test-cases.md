# 测试用例与验收矩阵

[开发任务](04-development-tasks.md) · [API 与数据模型](06-api-data-model.md)

生产验收按自建 Kubernetes、ACK、TKE 以及测试 ECS/CVM 检查真实接入。自动化使用脱敏夹具，以两个环境、两个同名资源、授权范围交叉的两类账号作为基础数据。

| 用例 | 级别 | 任务 | 操作与预期 |
| --- | --- | --- | --- |
| DC-UT01 | 浏览器 | T01 | 从原诊断控制台进入总览。核对汇总与最近结果。点击事件入口并搜索问题文本，总数和行一致。筛选无匹配时显示空态。 |
| DC-UT02 | 浏览器 | T01 | 从跨集群过滤后的事件表进入远程详情。返回并刷新，筛选、实例和页位置一致。既有 Finding 深链、旧导航和复核入口继续可用。 |
| DC-UT03 | 接口/浏览器 | T01/T03 | 未登录得到 401。只读者在其范围内可读，显式访问未授权范围返回 403；未授权实例的事件、计数与拓扑均不可见。失败且无法保证完整结果时显示可重试错误。 |
| DC-UT04 | 浏览器 | T02 | K8s 事件、Prometheus、VictoriaLogs 和 Alertmanager 四类均折叠。Enter 展开，AI 引用定位，复制文本脱敏。一个来源失败不清空其他来源。 |
| DC-UT05 | 单元/事务 | T03 | 幂等键与请求体一致重试复用 ID，内容不同返回 409。两端使用同一版本提交状态，只有一个写入成功。非法状态流转拒绝并保留记录。 |
| DC-UT06 | 单元/集成 | T04 | 重放同源事件仅保留一份。恢复先于告警到达时，旧 firing 不回退更新较新的状态。跨环境同名不归并。拆分后成员、时间线和计数同步更新。 |
| DC-UT07 | 集成/浏览器 | T05 | 启动任务后失败或超时。保存原输入与已有成功版。重试生成新任务，旧任务结束不能覆盖新任务。取消后验证无迟到提交。 |
| DC-UT08 | 单元/接口 | T05 | 模型返回伪造引用、只含历史线索、读取时范围变化。分别剔除无效引用、标记证据不足、阻止结论持久化且保留授权审计。 |
| DC-UT09 | 集成/浏览器 | T06 | 图中一个节点不可见，并存在环和缺失节点。返回结果有界，剔除越权边端点与衍生统计，显示覆盖范围。 |
| DC-UT10 | 接口/真实环境 | T07 | 禁用连接器、凭据失效、超时、恢复。各状态独立展示。列表、审计及错误响应不出现密钥或未过滤上游响应。 |
| DC-UT11 | 事务/集成 | T08 | 两人编辑同一策略产生版本冲突。重复触发进入冷却，禁用后保留历史但停止新任务。策略只能影响授权范围。 |
| DC-UT12 | 发布 | T01–T08 | 用旧代码读取加法迁移后的环境，复测 Findings、LDAP、用户组继承、审计、Wiki。新版本按环境启用和撤回。 |
