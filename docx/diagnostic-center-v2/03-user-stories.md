# 用户故事

[功能](02-features.md) · [开发任务](04-development-tasks.md)

| 编号 | 用户目标 | 可观察的验收标准 |
| --- | --- | --- |
| DC-US01 | 值班员从总览识别当前范围异常并定位详情。 | 切换环境后总数、分类、最近结果一致。两个集群出现相同 Finding ID 时，详情仍定位到正确实例。返回列表恢复筛选及游标。 |
| DC-US02 | 故障负责人追踪跨源故障及恢复情况。 | 生产 ACK 订单服务与已登记 ECS 数据库允许产生关联候选。另一个环境的同名对象无交叉聚合。重复提交不产生第二条事件，状态流转留痕。 |
| DC-US03 | 诊断人员核查证据和模型引用。 | 每类工具正文默认收起。键盘可展开。点击引用聚焦正确条目，缺失或越权引用给出明确状态。 |
| DC-US04 | 值班员补充现场观察后进行 AI 复核。 | 第二轮使用本轮输入和证据编号。超时保留观察和先前成功版本。模型候选上标记证据状态，结论保存沿用授权。 |
| DC-US05 | 业务运维确定故障影响范围。 | 点选依赖显示资源归属及关系来源。缺少拓扑数据时界面展示覆盖情况。越权节点和关系不可见。 |
| DC-US06 | 连接器管理员可对数据源进行配置和排障。 | 同一连接器的连接测试、启停及配置变更分别授权。失败可定位到超时、配置或上游授权问题。 |
| DC-US07 | 策略管理员在授权范围内启用自动诊断。 | 可查看规则版本及命中详情。重复告警命中冷却规则。禁用策略后不启动新任务，已有任务保留运行记录。 |
