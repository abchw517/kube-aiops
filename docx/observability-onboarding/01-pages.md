# 页面拆解

| 页面 | 区域 × 行为 |
| --- | --- |
| 资源管理／数据源管理 | Zabbix、Prometheus、VictoriaLogs、Alertmanager、Grafana 类型区和资产区。环境、状态筛选四类新连接，展开后维护。 |
| 接入或编辑弹窗 | 左侧名称、地址、认证，右侧授权范围与类型字段。连接成功后可预览，范围预览通过后可保存。窄屏纵向排列。 |
| 诊断总览 | 增加 Alertmanager 来源及活动或包含非活动过滤，覆盖提示、趋势和最近诊断同步反映当前范围。 |
| 故障与 K8sGPT 详情 | 共享既有指标、日志、告警证据区。范围匹配时附加 Grafana 仪表盘链接。 |
