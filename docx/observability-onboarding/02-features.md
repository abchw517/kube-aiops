# 功能拆解

| 模块 | 核心规则 |
| --- | --- |
| 接入验证 | API 侧执行固定只读查询。核对 HTTPS 白名单、上游权限和响应结构，空结果可预览。 |
| 连接维护 | SQLite 配置和密文，版本保护，审计、暂停、恢复和重测。 |
| 授权 | 目录范围与集群归属校验，告警按共享标签及命名空间归属复核后使用。 |
| 诊断证据 | 对已授权故障或 Finding 应用完全匹配的活动连接。继续使用原适配器的预算、证据结构与脱敏。 |
| 告警轮询 | 后台每分钟领取告警连接，受限快照和期限定长保留。重复返回幂等，失败保留上次成功快照。 |
| 仪表盘 | 发现并保存 Dashboard UID，详情按授权范围与锚点生成 HTTPS 链接。 |
