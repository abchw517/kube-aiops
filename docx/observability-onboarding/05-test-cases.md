# 测试用例

| 用例 | 验收 |
| --- | --- |
| T01 | 四类连接在原型和管理页可选；编辑时范围与类型保留，保存时服务端重新验证。 |
| T02 | 尝试非 HTTPS、带凭据 URL、非允许路径和跨环境业务组合，拒绝请求。 |
| T03 | 凭据验证成功后保存密文，读接口、告警回包与审计记录不输出用户名或密码。 |
| T04 | Prometheus 空向量返回 0，VictoriaLogs 无结果可预览，异常响应时报上游不可用。 |
| T05 | Alertmanager 重复记录去重、共享端点标签拦住其他集群、静默单列。上游消失记录标记已离开列表。 |
| T06 | Grafana 拒绝未发现的 UID，不使用上游返回链接，详情链接包含诊断 30 分钟窗口。 |
| T07 | 服务按范围解析新连接，原有部署证据仍在原集群回退，跨业务拒绝关联。 |
| T08 | 新增告警在生产 CSP 下提供趋势和来源明细。资产与 Zabbix 的页面操作回归通过。 |
