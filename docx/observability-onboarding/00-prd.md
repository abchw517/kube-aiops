# PRD · 可观测数据源接入

目标是让平台维护人按同一界面配置四类可观测连接，并让值班人直接从诊断查看证据、告警和仪表盘。连接范围按环境、业务和集群约束。

| 需求 | 验收 |
| --- | --- |
| R1 统一接入 | 保持 Zabbix 和资产区入口。四类新连接可折叠、筛选、测试、预览、保存、编辑和启停。 |
| R2 授权范围 | 通用流程要求授权范围，支持共享端点的固定标签，VictoriaLogs 支持租户，凭据写后不可查看。 |
| R3 指标、日志和告警证据 | 新连接作为同范围诊断的适配器，保留原有固定查询模板和部署配置。 |
| R4 Alertmanager 总览 | 轮询成功后的活动告警进入总览，按源筛选后可选择查看近期离开列表和静默记录。 |
| R5 Grafana 跳转 | 仅提供已保存且获授权的 Dashboard 链接，携带诊断时间范围。 |
