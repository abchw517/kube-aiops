# 资源管理工作区 PRD

## 目标与用户

值班运维通过当前环境的摘要和列表发现错误、看证据并重试，平台管理员通过同一个入口选择数据源或集群的接入方式。只读人员可在授权范围内查看详情并使用允许的诊断跳转。

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| DS-01 | 数据源巡检 | 两个页签都可按名称、环境、类型和状态筛选；摘要只统计已读取的授权数据；分组折叠不清空筛选 |
| DS-02 | 统一接入 | 监控页签提供 Zabbix、Prometheus、VictoriaLogs、Alertmanager、Grafana；资产页签提供 ECS、CVM；缺少相应权限时隐藏入口 |
| DS-03 | 操作与失败恢复 | 同步后台执行，测试记录一次连接结果，写操作携带版本；同一行处理中不可重复发起；单来源不可用时其余来源可用 |
| DS-04 | 范围与历史 | 资产保持游标，页面注明统计口径；部署配置只读展示；有历史快照的失败实例显示上次成功信息 |
| CL-01 | 集群巡检 | 摘要、环境、接入方式和关键词联动；节点状态和采集进度可独立阅读；最新校验失败时快照标记为历史 |
| CL-02 | 命名空间定位 | 两个视图共享环境，关键词分别保留；可按实例区分不同集群的同名命名空间；失败提示可追溯至采集详情 |
| CL-03 | 接入与编辑 | 可以选择外部直连或采集上报；表单分区，锁定环境与实例 ID；待补录直连实例直接打开连接分区 |
| CL-04 | 维护与授权 | 校验、归属、凭据轮换、删除和重新连接按模式与权限显示；上报凭据一次性显示；列表刷新恢复当前筛选 |

## 交付边界

前端沿用已经上线的数据采集时效、API 连通验证、授权策略、审计记录、诊断路由与所有历史兼容记录。首次等待、无匹配结果、权限拒绝和请求失败都有各自反馈。原型演示的临时数据与权限切换由真实接口替代。
