# 页面拆解

| 页面区域 | 数据源管理 | Kubernetes 集群管理 |
| --- | --- | --- |
| 标题和主操作 | 数据源管理，新增数据源 | Kubernetes 集群管理，接入集群 |
| 视图切换 | 监控与诊断／资产数据源 | 集群列表／命名空间 |
| 摘要 | 已接入、需处理、暂停或停用 | 全部集群、需处理、等待采集 |
| 筛选 | 名称、环境、类型、状态；可按类型分组 | 集群名称、实例名称或 ID、环境、接入方式、状态；命名空间按名称、环境和实例 |
| 表格 | 名称与类型、所属范围、状态、最近活动、操作 | 集群与实例 ID、环境与业务线、接入方式、采集状态、节点状态、最近活动、操作 |
| 右侧详情 | 运行记录、连接与范围、快照或可见资产、操作 | 节点、命名空间、K8sGPT、最近检查或上报、重新校验 |
| 接入弹窗 | 类型选择，连接、范围预览或资产表单 | 方式选择，基本信息、连接与凭据、观测与诊断 |
| 其他 | 部署配置、资产游标、来源失败重试 | 命名空间归属、连接删除、重新连接、凭据轮换 |

在 680px 及以下宽度，列表按条目排列，操作保留在条目尾部。连接器测试、范围预览和保存使用固定底栏。集群编辑正文滚动，标题和操作可持续访问。列表在权限不足时仍保留合适的查看入口。
