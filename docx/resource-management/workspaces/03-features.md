# 功能拆解

| 功能 | 状态规则 | 接口与关键限制 |
| --- | --- | --- |
| 三来源汇总与重试 | 失败单独提示，其他来源仍可操作 | Zabbix、观测、资产原有 GET；按来源与 ID 区分记录 |
| Zabbix 接入和维护 | 验证连接后发现主机组，任一范围变更使之前预览失效 | 支持 Token、账号密码；复用预览、草稿和 If-Match 更新；详情保留诊断总览 |
| 观测接入与探索 | 连接测试后预览，表单修改使旧结果失效 | Prometheus 查询指标、VictoriaLogs 查询日志与租户、Alertmanager 只读轮询、Grafana 发现并选择仪表盘 |
| 云资产接入 | 保存后测试并同步；禁用、恢复更新版本 | ECS 或 CVM，凭据和推送引用由后端维护；历史 Zabbix 资产可编辑；可见资产遵守授权 |
| 集群环境、模式与状态 | 节点失效、离线、待补录、权限失败进入需处理；正常等待和停用单独分类 | 使用现有集群接入 GET；环境及其他筛选记录在路由查询中 |
| 采集详情与校验 | 上报显示最近上报；直连和本地显示检查及采样；历史节点不参与当前判断 | 对启用的本地或已配置凭据的直连实例执行 recheck |
| 集群编辑与上报 | 首采后环境只读；配置校验定位分区；上报保存后展示一次性凭据 | POST/PUT 接入目录，凭据方式与原 payload 兼容；启停沿用实例配置 |
| 命名空间管理 | 当前环境下按实例查找，异常实例显示缺数提示 | namespace-business 接口按业务线保存增删；已保存的其他业务不受影响 |
| 接入维护 | 删除确认包含目标 ID；本地保留恢复入口；轮换上报凭据说明旧凭据立即失效 | 原有 DELETE、reconnect 和 rotate-token 操作 |
