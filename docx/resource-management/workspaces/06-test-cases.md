# 资源管理测试用例

| 编号 | 前提和步骤 | 预期结果 | 验证方式 |
| --- | --- | --- | --- |
| DS-T01 | 访问旧数据源地址并携带资产游标 | 进入资源管理菜单，资产页签保留游标 | 浏览器回归 |
| DS-T02 | 打开资产页签新增，选择 CVM，填写资产信息后测试 | 新增只列 ECS/CVM，保存成功后状态和已同步资产可见 | 浏览器回归 |
| DS-T03 | 接入 Zabbix，先给出不允许的地址，再填写合法地址、环境、业务、主机组和名称 | 拒绝原因清楚，错误可重试，预览后保存；名称和归属持久化 | 浏览器回归 |
| DS-T04 | Zabbix 类型分组折叠并展开，打开详情跳转诊断总览 | 只控制该类型展开，诊断总览仍使用对应的数据源范围 | 浏览器回归 |
| DS-T05 | 接入共享 Alertmanager，填写环境、业务、实例和映射 | 测试、活动告警预览、保存和诊断总览链路通过 | 浏览器回归 |
| DS-T06 | 观测列表失败且 Zabbix 列表成功 | 已收到的 Zabbix 仍展示，观测可重试，摘要表明只统计已加载来源 | 浏览器回归 |
| DS-T07 | 停用、有历史快照的同步失败、已启用的按需数据源 | 状态分类与标签准确，停用不算故障，验证时间不等同于同步 | 单元测试 |
| DS-T08 | 修改草稿、版本冲突、暂停或恢复 | 草稿保留，冲突提示最新版本，暂停提示影响，响应更新对应记录 | 验收检查 |
| CL-T01 | 按环境和需处理筛选，切换命名空间并选择实例 | 摘要状态与列表一致，环境共享，实例和关键词生效 | 浏览器回归 |
| CL-T02 | 查看 NotReady、Kubernetes 校验失败和节点过期样本 | 节点与采集状态独立，失败覆盖历史 Ready 判断 | 单元／浏览器 |
| CL-T03 | 在详情重新校验，再切换列表视图 | 详情保持打开，时间及状态更新，列表范围可恢复 | 浏览器回归 |
| CL-T04 | 编辑共用集群归属，切换业务线后分别保存 | 草稿各自恢复，当前业务提交最小差异，固定保存条可见 | 浏览器回归 |
| CL-T05 | 编辑首采成功的外部直连，新增上报集群 | 环境只读，查看编辑分区，上报保存结果显示一次性凭据 | 浏览器回归 |
| CL-T06 | 删除后取消；随后确认删除本地连接并重新连接 | 取消无副作用，已解除连接可在同一筛选下恢复 | 浏览器回归 |
| UI-T01 | 在桌面和 390px 下查看详情、表单和列表 | 列表无整页横向溢出，底部操作可访问，隐藏内容失焦 | 浏览器回归 |
| UI-T02 | 只读、目录失败、无集群或无数据源 | 写入入口受限，失败与空列表不同，恢复后显示可用数据 | 验收检查 |

执行 `make web-check` 验证 lint、类型、单元测试和构建。执行 `make web-e2e` 通过真实前端与模拟 API 完成浏览器回归。
