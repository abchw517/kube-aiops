# 用户故事

| 故事 | 角色与目标 | 行为与结果 |
| --- | --- | --- |
| US-01 | 作为值班运维，我要快速确认生产的数据源故障 | 在监控与诊断筛选环境和「需处理」，详情查看上次成功或最近验证，在适用时重试 |
| US-02 | 作为可观测性管理员，我要接入外部监控并预览授权范围 | 选择连接器后填写范围。Zabbix 选主机组，Grafana 选仪表盘，共享端点填写映射，验证后启用 |
| US-03 | 作为资产管理员，我要接入云主机并核对已同步的实例 | 切到资产页签选择 ECS 或 CVM，保存、测试并同步，展开可见资产 |
| US-04 | 作为 Kubernetes 值班人员，我要定位节点异常或采集离线 | 按环境和问题筛选，核对采集状态与节点状态，查看快照和最近尝试并按需重新校验 |
| US-05 | 作为应用运维，我要查到指定环境下某个集群的命名空间 | 在命名空间视图保留环境并选择集群，以实例 ID 区分同名集群，查看归属和采集说明 |
| US-06 | 作为平台管理员，我要在不同网络条件下接入集群 | 选择外部直连或采集上报，填写各自所需配置。保存上报实例后获取一次性凭据 |
| US-07 | 作为资源管理员，我要调整某条业务线的命名空间归属 | 编辑同一集群的多条业务线时，各条草稿分别保留。一次保存只提交当前业务线的变化 |
| US-08 | 作为只读协作者，我要查看采集和数据源证据 | 在权限范围内查看记录和详情，写入入口按角色隐藏 |
