# 平台目录改版 PRD

目录维护面向平台管理员，目录检索和复制面向可读取目录的人员。目标是缩短日常名称变更路径，增加标识变更的可预期性，并让删除异常可以定位到配置对象。

| 需求 | 行为与验收 |
| --- | --- |
| RC-01 统一目录布局 | 两个独立路由有同一布局，根据读取权限显示页签。搜索支持名称和 ID，显示结果数／总数。返回目录时保留该页搜索和排序。 |
| RC-02 新增条目 | 有写权限时可从页首进入。名称和 ID 校验通过后提交，返回成功后立即展示；不匹配当前搜索时提示清空搜索。 |
| RC-03 常规编辑 | 打开表单直接编辑名称，当前 ID 默认锁定。只修改名称沿用原 ID；正式保存前支持取消草稿。 |
| RC-04 ID 变更 | 显式解锁后输入新 ID。提示历史别名及外部配置影响。保存传原 ID；字段错误保留稿件并聚焦。 |
| RC-05 引用冲突 | 删除确认明确名称与 ID。当服务端返回引用冲突，在当前弹窗展示清单；可复制并重试。 |
| RC-06 状态恢复 | 只读支持查询、查看和复制。请求失败允许重试，提交失败保留字段和目录数据；页面可在窄屏使用。 |

验收以现有接口的返回结果和权限范围为准。原型中的演示场景在应用中由响应及权限驱动。
