# 页面拆解

| 区域 | 环境管理 | 业务线管理 |
| --- | --- | --- |
| 标题及操作 | 环境管理及新增环境 | 业务线管理及新增业务线 |
| 目录切换 | 环境、业务线，显示已授权入口 | 同一套目录导航 |
| 工具栏 | 名称或 ID 搜索，目录顺序／名称／ID 排序 | 独立保留本页筛选 |
| 列表 | 环境名称、环境 ID、操作 | 业务线名称、业务线 ID、操作 |
| 右侧详情 | 名称、当前 ID、关联用途 | 名称、当前 ID、命名空间归属用途 |
| 新增及编辑 | 名称、ID，编辑时默认锁定 ID | 共用表单，显示业务线示例 |
| 删除弹窗 | 当前对象、确认、引用清单 | 支持集群／命名空间及角色引用 |
| 空态与权限 | 清空搜索、重新加载或显示只读 | 同一布局，使用业务线文案 |

表单头部、内容、底栏为独立区域。内容溢出时只滚动正文，底部放取消与保存。普通列表在 680px 及以下以条目排列。
