# 功能拆解

| 功能 | 核心规则 |
| --- | --- |
| 授权读取 | 使用资源导航已有读取权限，读取失败可原地重试，401 与 403 由既有登录和无权限入口处理首屏。 |
| 查询与排序 | 搜索忽略大小写和首尾空白，目录顺序来自服务端，名称／ID 排序只影响当前显示。 |
| 复制 ID | 优先写入剪贴板，权限限制时给出可选中的文本。只读账号也可使用。 |
| 名称校验 | 去除首尾空白，非空，最多 128 个 Unicode 字符，拒绝控制字符。客户端即时查当前条目，服务端核对历史名称。 |
| ID 校验 | 新 ID 使用小写字母开头，含小写字母、数字或连字符，最多 128 字符。已有历史格式 ID 原样编辑名称仍可提交。 |
| 更新请求 | 发送原 ID 与目标字段。使用返回的实际条目更新当前列表及详情。 |
| 删除引用 | 服务端核查后接受或拦截，按原始返回展示引用，应用仅提供可解释的类型标签。 |
| 草稿 | 无改动时保存禁用；修改后关闭或按 Esc 时确认；失败保留输入，进行中阻止重复操作。 |
