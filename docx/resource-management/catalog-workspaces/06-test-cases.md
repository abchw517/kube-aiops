# 平台目录测试用例

| 编号 | 前置与操作 | 预期 | 回归 |
| --- | --- | --- | --- |
| RC-T01 | 访问环境管理，搜索不存在的名称，切到业务线再返回 | 显示筛选无结果；返回后环境关键词保留，清空可恢复 | 浏览器 |
| RC-T02 | 新增时填写大写 ID；使用 128 字符边界和非法名称 | 大写 ID、超长及控制字符被拦截，合法 ID 可用 | 浏览器／单元 |
| RC-T03 | 打开环境详情并编辑，只改名称，先取消再继续编辑并保存 | ID 默认锁定，确认后可保留草稿；保存后列表和详情都反映新名称 | 浏览器 |
| RC-T04 | 解锁现有 ID，提交占用的历史 ID，再提交合法新 ID | 历史冲突提示至 ID 字段，原内容保留；合法更新通过 | 浏览器 |
| RC-T05 | 不解锁 ID，为历史格式 ID 条目改名称 | 名称允许保存，原 ID 原样保留 | 单元 |
| RC-T06 | 删除有引用的环境和业务线 | 弹窗显示集群、命名空间或角色引用；取消保留条目，可复制清单 | 浏览器 |
| RC-T07 | 新增时模拟服务失败，再恢复并重试；删除该无引用对象 | 错误保留草稿，成功展示并可删除 | 浏览器 |
| RC-T08 | 只读进入业务线目录 | 列表可查、复制入口可用，写入口隐藏 | 浏览器／单元 |
| RC-T09 | 模拟目录读取失败，然后重试 | 错误区别于空目录，重试恢复当前列表 | 浏览器 |
| RC-T10 | 390px 查看列表和编辑弹窗 | 页面无横向溢出，底部保存按钮仍在视口里 | 浏览器 |
| RC-T11 | 按 ID 排序，查名称或 ID | 排序不修改来源列表，查询忽略大小写 | 单元 |
| RC-T12 | 浏览器剪贴板权限阻止写入，复制 ID 或引用 | 提供只读、可选择的文本 | 浏览器 |

运行 `make web-check` 和 `make web-e2e` 核对实现。浏览器回归使用现有 Portal 构建和模拟 API。
