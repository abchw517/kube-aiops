## 功能及验收边界

### RM-F01

**导航与集群列表** · PRD §2、§4 · 页面 [RM-P01](01-pages.md#rm-p01)

点击资源管理进入集群列表；环境查看者只获得可见集群；未归属本地集群仅系统管理员可见；直接访问也校验。

对应用户故事 [RM-US01](03-user-stories.md#rm-us01)

### RM-F02

**本地识别与归属补录** · PRD §3、§4、§5.1 · 页面 [RM-P01](01-pages.md#rm-p01)、[RM-P02](01-pages.md#rm-p02)

首次启动自动建连并开始采集；重启复用现有记录；补录有效环境、业务线和名称后按当前权限可见。

对应用户故事 [RM-US02](03-user-stories.md#rm-us02)

### RM-F03

**外部集群接入** · PRD §3、§4、§5.2 · 页面 [RM-P02](01-pages.md#rm-p02)

三项归属必填；每次使用一种凭据；成功保存后创建者获得集群管理权限；同一 Kubernetes 集群只保留一条连接。

对应用户故事 [RM-US03](03-user-stories.md#rm-us03)

### RM-F04

**校验失败与手动重试** · PRD §5.2 · 页面 [RM-P02](01-pages.md#rm-p02)、[RM-P03](01-pages.md#rm-p03)

区分网络不可达与节点读取权限不足；失败可存待接入并显示原因；成功重校验开始首采窗口；待接入无定时重试。

对应用户故事 [RM-US04](03-user-stories.md#rm-us04)

### RM-F05

**首采及状态转换** · PRD §5.2、§5.3、§8 · 页面 [RM-P03](01-pages.md#rm-p03)

校验后 5 分钟内等待；节点或真实诊断到达即已接入；边界无数据则超时；仅诊断到达且无节点达到边界时显示节点采集异常；迟到数据按规则恢复。

对应用户故事 [RM-US05](03-user-stories.md#rm-us05)

### RM-F06

**节点健康、诊断提示及过期** · PRD §5.3 · 页面 [RM-P03](01-pages.md#rm-p03)

节点每 5 分钟采集；NotReady 单独标出；连续两轮失败显示过期并保留最近成功快照与时间；成功后恢复。节点全 Ready 时按诊断采集情况单列提示。

对应用户故事 [RM-US06](03-user-stories.md#rm-us06)

### RM-F07

**追加集群业务线** · PRD §3 · 页面 [RM-P04](01-pages.md#rm-p04)

追加后原连接、环境、凭据和历史保留；重复提交得到同一关联集合。

对应用户故事 [RM-US07](03-user-stories.md#rm-us07)

### RM-F08

**命名空间多对多分配** · PRD §3、§4 · 页面 [RM-P04](01-pages.md#rm-p04)、[RM-P07](01-pages.md#rm-p07)、[RM-P08](01-pages.md#rm-p08)

授权用户可更新集合；至少一条即已分配；全部移除成为待分配；历史按当前关系展示。

对应用户故事 [RM-US08](03-user-stories.md#rm-us08)

### RM-F09

**环境维护与删除保护** · PRD §3、§4、§6.3、§8 · 页面 [RM-P05](01-pages.md#rm-p05)

初始化研发、测试、预发布、生产；授权可新增改名；活跃集群引用阻止删除并返回引用。

对应用户故事 [RM-US09](03-user-stories.md#rm-us09)

### RM-F10

**环境管理员委派及环境授权** · PRD §4 · 页面 [RM-P05](01-pages.md#rm-p05)

系统管理员及环境管理者可指定环境管理员；仅系统管理员可撤销；环境管理员在负责环境内授予权限；环境撤权使该环境集群授权失效，重新授权后需重授集群权限。

对应用户故事 [RM-US10](03-user-stories.md#rm-us10)

### RM-F11

**集群授权** · PRD §4 · 页面 [RM-P03](01-pages.md#rm-p03)

只有有权授予的人可操作；接收人已有当前环境权限；环境查看者无法修改集群；操作以服务端授权为准。

对应用户故事 [RM-US11](03-user-stories.md#rm-us11)

### RM-F12

**业务线维护与删除保护** · PRD §3、§4、§6.3、§8 · 页面 [RM-P06](01-pages.md#rm-p06)

业务线跨环境共用；只有业务线管理权限可写；集群或命名空间任一活跃引用阻止删除。

对应用户故事 [RM-US12](03-user-stories.md#rm-us12)

### RM-F13

**环境历史诊断** · PRD §2、§3、§4、§6.1 · 页面 [RM-P07](01-pages.md#rm-p07)

集群详情含集群级诊断及已分配命名空间诊断；命名空间详情仅含该空间；无当前环境权限时不能通过直链读取。

对应用户故事 [RM-US13](03-user-stories.md#rm-us13)

### RM-F14

**业务线历史诊断** · PRD §2、§3、§4 · 页面 [RM-P08](01-pages.md#rm-p08)

同一空间关联两条业务线时结果一致；解除其中一条立即隐藏；业务线详情仅含关联命名空间诊断。

对应用户故事 [RM-US14](03-user-stories.md#rm-us14)

### RM-F15

**集群环境迁移** · PRD §4、§6.1 · 页面 [RM-P03](01-pages.md#rm-p03)、[RM-P07](01-pages.md#rm-p07)、[RM-P08](01-pages.md#rm-p08)

两个权限均满足，环境改变后保留集群 ID、业务线、命名空间和历史时间；仅保留已有目标环境权限用户的原授权。

对应用户故事 [RM-US15](03-user-stories.md#rm-us15)

### RM-F16

**外部凭据轮换** · PRD §6.2 · 页面 [RM-P02](01-pages.md#rm-p02)、[RM-P03](01-pages.md#rm-p03)

成功才切换；失败保留原配置并说明原因；原凭据也失效时提示凭据失效，过期规则照常。

对应用户故事 [RM-US16](03-user-stories.md#rm-us16)

### RM-F17

**删除集群连接** · PRD §6.3 · 页面 [RM-P03](01-pages.md#rm-p03)

清理节点、资源和诊断；保留已发布知识库文档；后台旧任务无法回写已删除连接。

对应用户故事 [RM-US17](03-user-stories.md#rm-us17)

### RM-F18

**本地删除状态与重新连接** · PRD §5.1、§6.3、§8 · 页面 [RM-P03](01-pages.md#rm-p03)

系统重启仍为已删除且不采集；管理员点击重新连接沿用名称、环境和业务线；开始新一轮采集，已清理的历史保持清理状态。

对应用户故事 [RM-US18](03-user-stories.md#rm-us18)

首版范围与 PRD 保持一致。远端主动上报、待接入定时重试、许可证和计费属于后续范围。
