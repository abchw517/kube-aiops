# 资源管理 · 功能拆解

[设计方案](design.md) · [PRD](00-prd.md) · [页面拆解](01-pages.md) · [用户故事](03-user-stories.md) · [开发任务](04-development-tasks.md) · [测试用例](05-unit-test-cases.md) · [交互原型](prototype.html) · [文档维护规则](../development-standard.md)

覆盖环境管理、业务线管理、Kubernetes 集群与命名空间，以及监控诊断和资产数据源。环境与业务线采用当前平台目录交互，集群与数据源采用当前工作区及专项编辑流程。

## 环境与业务线目录

| 功能 | 核心规则 |
| --- | --- |
| 授权读取 | 使用资源导航已有读取权限，读取失败可原地重试，401 与 403 由既有登录和无权限入口处理首屏。 |
| 查询与排序 | 搜索忽略大小写和首尾空白，目录顺序来自服务端，名称／ID 排序只影响当前显示。 |
| 复制 ID | 优先写入剪贴板，权限限制时给出可选中的文本。只读账号也可使用。 |
| 名称校验 | 去除首尾空白，非空，最多 128 个 Unicode 字符，拒绝控制字符。客户端即时查当前条目，服务端核对历史名称。 |
| ID 校验 | 新 ID 使用小写字母开头，含小写字母、数字或连字符，最多 128 字符。已有历史格式 ID 原样编辑名称仍可提交。 |
| 更新请求 | 发送原 ID 与目标字段。使用返回的实际条目更新当前列表及详情。 |
| 删除引用 | 服务端核查后接受或拦截，按原始返回展示引用，应用仅提供可解释的类型标签。 |
| 草稿 | 无改动时保存禁用；修改后关闭或按 Esc 时确认；失败保留输入，进行中阻止重复操作。 |

## 集群与数据源工作区

| 功能 | 状态规则 | 接口与关键限制 |
| --- | --- | --- |
| 三来源汇总与重试 | 失败单独提示，其他来源仍可操作 | Zabbix、观测、资产原有 GET；按来源与 ID 区分记录 |
| Zabbix 接入和维护 | 验证连接后发现主机组，任一范围变更使之前预览失效 | 支持 Token、账号密码；复用预览、草稿和 If-Match 更新；详情保留诊断总览 |
| 观测接入与探索 | 连接测试后预览，表单修改使旧结果失效 | Prometheus 查询指标、VictoriaLogs 查询日志与租户、Alertmanager 只读轮询、Grafana 发现并选择仪表盘 |
| 云资产接入 | 保存后测试并同步；禁用、恢复更新版本 | ECS 或 CVM，凭据和推送引用由后端维护；历史 Zabbix 资产可编辑；可见资产遵守授权 |
| 集群环境、模式与状态 | 节点失效、离线、待补录、权限失败进入需处理；正常等待和停用单独分类 | 使用现有集群接入 GET；环境及其他筛选记录在路由查询中 |
| 采集详情与校验 | 上报显示最近上报；直连和本地显示检查及采样；历史节点不参与当前判断 | 对启用的本地或已配置凭据的直连实例执行 recheck |
| 集群编辑与上报 | 首采后环境只读；配置校验定位分区；上报保存后展示一次性凭据 | POST/PUT 接入目录，凭据方式与原 payload 兼容；启停沿用实例配置 |
| 命名空间管理 | 当前环境下按实例查找，异常实例显示缺数提示 | namespace-business 接口按业务线保存增删；已保存的其他业务不受影响 |
| 接入维护 | 删除确认包含目标 ID；本地保留恢复入口；轮换上报凭据说明旧凭据立即失效 | 原有 DELETE、reconnect 和 rotate-token 操作 |

## 可观测数据源接入

连接器契约和部署配置见本节。列表布局与新增入口以集群与数据源工作区为准。

| 模块 | 核心规则 |
| --- | --- |
| 接入验证 | API 侧执行固定只读查询。核对 HTTPS 白名单、上游权限和响应结构，空结果可预览。 |
| 连接维护 | SQLite 配置和密文，版本保护，审计、暂停、恢复和重测。 |
| 授权 | 目录范围与集群归属校验，告警按共享标签及命名空间归属复核后使用。 |
| 诊断证据 | 对已授权故障或 Finding 应用完全匹配的活动连接。继续使用原适配器的预算、证据结构与脱敏。 |
| 告警轮询 | 后台每分钟领取告警连接，受限快照和期限定长保留。重复返回幂等，失败保留上次成功快照。 |
| 仪表盘 | 发现并保存 Dashboard UID，详情按授权范围与锚点生成 HTTPS 链接。 |

## Zabbix 接入与同步

数据源在监控与诊断页签中配置。诊断结果、趋势和授权可见性见[诊断控制台](../diagnosis-console/design.md)。

| 模块 | 接口与实现 |
| --- | --- |
| 验证连接 | `POST /api/v1/diagnostics/zabbix/test`。返回版本、可读主机组和短期验证引用。 |
| 环境／业务目录 | 打开窗口时调用 `GET /api/v1/diagnostics/zabbix/scopes`。左侧显示有维护权限的环境，右侧只显示所选环境的授权业务。目录加载失败时可重试。 |
| 范围与问题预览 | `POST /api/v1/diagnostics/zabbix/preview`。通过验证引用或受权的数据源读取选中主机组。 |
| 数据源维护 | `POST /api/v1/diagnostics/zabbix/sources` 接收 `name` 并校验长度和字符。`GET` 返回已保存的 `name`。旧版调用方可省略该字段。`PATCH /api/v1/diagnostics/zabbix/sources/{sourceId}` 通过 `If-Match` 检查配置版本。 |
| 列表折叠 | 标题按钮更新 `aria-expanded`，同步隐藏或显示列表内容。接入操作位于折叠内容外，保存后展开列表。 |
| 同步调度 | `POST /api/v1/diagnostics/zabbix/sources/{sourceId}/sync` 进入后台调度。默认每分钟重新检查。 |
| 诊断数据 | `GET /api/v1/diagnostics/zabbix/problems`，按环境、业务及恢复状态返回经权限裁剪的问题与来源健康状态。 |
| 授权与审计 | 复用 `diagnosis.connector.read/write/test`。主机授权只匹配环境、业务。保存变更和手动触发同步记录不含凭据的审计事件。 |

### 功能及验收边界

#### RM-F01

**导航与集群列表** · PRD §2、§4 · 页面 [RM-P01](01-pages.md#rm-p01)

点击资源管理默认进入「Kubernetes 集群管理」，导航和标题采用相同名称。环境查看者只获得可见集群；未归属本地集群仅系统管理员可见；直接访问也校验。

对应用户故事 [RM-US01](03-user-stories.md#rm-us01)

#### RM-F02

**本地识别与归属补录** · PRD §3、§4、§5.1 · 页面 [RM-P01](01-pages.md#rm-p01)、[RM-P02](01-pages.md#rm-p02)

首次启动自动建连并开始采集；重启复用现有记录；补录有效环境、业务线和名称后按当前权限可见。

对应用户故事 [RM-US02](03-user-stories.md#rm-us02)

#### RM-F03

**外部集群接入** · PRD §3、§4、§5.2 · 页面 [RM-P02](01-pages.md#rm-p02)

三项归属必填；每次使用一种凭据；成功保存后创建者获得集群管理权限；同一 Kubernetes 集群只保留一条连接。

对应用户故事 [RM-US03](03-user-stories.md#rm-us03)

#### RM-F04

**校验失败与手动重试** · PRD §5.2 · 页面 [RM-P02](01-pages.md#rm-p02)、[RM-P03](01-pages.md#rm-p03)

区分网络不可达与节点读取权限不足；失败可存待接入并显示原因；成功重校验开始首采窗口；待接入无定时重试。

对应用户故事 [RM-US04](03-user-stories.md#rm-us04)

#### RM-F05

**首采及状态转换** · PRD §5.2、§5.3、§8 · 页面 [RM-P03](01-pages.md#rm-p03)

校验后 5 分钟内等待；节点或真实诊断到达即已接入；边界无数据则超时；仅诊断到达且无节点达到边界时显示节点采集异常；迟到数据按规则恢复。

对应用户故事 [RM-US05](03-user-stories.md#rm-us05)

#### RM-F06

**节点健康、诊断提示及过期** · PRD §5.3 · 页面 [RM-P03](01-pages.md#rm-p03)

节点每 5 分钟采集；NotReady 单独标出；连续两轮失败显示过期并保留最近成功快照与时间；成功后恢复。节点全 Ready 时按诊断采集情况单列提示。

对应用户故事 [RM-US06](03-user-stories.md#rm-us06)

#### RM-F07

**追加集群业务线** · PRD §3 · 页面 [RM-P04](01-pages.md#rm-p04)

追加后原连接、环境、凭据和历史保留；重复提交得到同一关联集合。

对应用户故事 [RM-US07](03-user-stories.md#rm-us07)

#### RM-F08

**命名空间多对多分配** · PRD §3、§4 · 页面 [RM-P04](01-pages.md#rm-p04)、[RM-P07](01-pages.md#rm-p07)、[RM-P08](01-pages.md#rm-p08)

授权用户可更新集合；至少一条即已分配；全部移除成为待分配；历史按当前关系展示。

对应用户故事 [RM-US08](03-user-stories.md#rm-us08)

#### RM-F09

环境 ID 可编辑。更新目录 ID 后，集群环境和权限范围继续引用同一环境。

**环境维护与删除保护** · PRD §3、§4、§6.3、§8 · 页面 [RM-P05](01-pages.md#rm-p05)

初始化研发、测试、预发布、生产；授权可新增改名；活跃集群引用阻止删除并返回引用。

对应用户故事 [RM-US09](03-user-stories.md#rm-us09)

#### RM-F10

**环境管理员委派及环境授权** · PRD §4 · 页面 [RM-P05](01-pages.md#rm-p05)

系统管理员及环境管理者可指定环境管理员；仅系统管理员可撤销；环境管理员在负责环境内授予权限；环境撤权使该环境集群授权失效，重新授权后需重授集群权限。

对应用户故事 [RM-US10](03-user-stories.md#rm-us10)

#### RM-F11

**集群授权** · PRD §4 · 页面 [RM-P03](01-pages.md#rm-p03)

只有有权授予的人可操作；接收人已有当前环境权限；环境查看者无法修改集群；操作以服务端授权为准。

对应用户故事 [RM-US11](03-user-stories.md#rm-us11)

#### RM-F12

业务线 ID 可编辑。更新目录 ID 后，现有集群、命名空间和授权关联继续生效。

**业务线维护与删除保护** · PRD §3、§4、§6.3、§8 · 页面 [RM-P06](01-pages.md#rm-p06)

业务线跨环境共用；只有业务线管理权限可写；集群或命名空间任一活跃引用阻止删除。

对应用户故事 [RM-US12](03-user-stories.md#rm-us12)

#### RM-F13

**环境历史诊断** · PRD §2、§3、§4、§6.1 · 页面 [RM-P07](01-pages.md#rm-p07)

集群详情含集群级诊断及已分配命名空间诊断；命名空间详情仅含该空间；无当前环境权限时不能通过直链读取。

对应用户故事 [RM-US13](03-user-stories.md#rm-us13)

#### RM-F14

**业务线历史诊断** · PRD §2、§3、§4 · 页面 [RM-P08](01-pages.md#rm-p08)

同一空间关联两条业务线时结果一致；解除其中一条立即隐藏；业务线详情仅含关联命名空间诊断。

对应用户故事 [RM-US14](03-user-stories.md#rm-us14)

#### RM-F15

**首采前修正集群环境** · 页面 [RM-P03](01-pages.md#rm-p03)

系统管理员可在首采前修正环境并保留集群 ID 和其他归属。收到节点状态或真实 K8sGPT 诊断后锁定环境。

对应用户故事 [RM-US15](03-user-stories.md#rm-us15)

#### RM-F16

**外部凭据轮换** · PRD §6.2 · 页面 [RM-P02](01-pages.md#rm-p02)、[RM-P03](01-pages.md#rm-p03)

成功才切换；失败保留原配置并说明原因；原凭据也失效时提示凭据失效，过期规则照常。

对应用户故事 [RM-US16](03-user-stories.md#rm-us16)

#### RM-F17

**删除集群连接** · PRD §6.3 · 页面 [RM-P03](01-pages.md#rm-p03)

清理节点、资源和诊断；保留已发布知识库文档；后台旧任务无法回写已删除连接。

对应用户故事 [RM-US17](03-user-stories.md#rm-us17)

#### RM-F18

**本地删除状态与重新连接** · PRD §5.1、§6.3、§8 · 页面 [RM-P03](01-pages.md#rm-p03)

系统重启仍为已删除且不采集；管理员点击重新连接沿用名称、环境和业务线；开始新一轮采集，已清理的历史保持清理状态。

对应用户故事 [RM-US18](03-user-stories.md#rm-us18)

首版范围与 PRD 保持一致。远端主动上报、待接入定时重试、许可证和计费属于后续范围。
