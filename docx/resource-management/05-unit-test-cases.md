## 执行说明

- 下列是待编码的单元测试规格。Go 使用表驱动测试、可注入时钟、模拟 Kubernetes 客户端与内存仓储；Web 使用 `web/tests` 现有 Node 测试入口测试路由和视图逻辑。
- 各用例独立准备数据并执行单个服务、策略或渲染函数。用注入错误验证失败后状态。采集测试推进假时钟，使用合成节点及 K8sGPT 诊断数据。
- 基础夹具使用研发/测试两个环境、一个本地及一个外部集群、`dev-base`、有数和云帆。角色夹具覆盖系统管理员、环境管理者、环境管理员、环境查看者、集群管理员和无权 OPS。
- 验证真实 API Server、数据库事务和浏览器操作分别使用集成、端到端及试点验收。表中事务单测通过模拟写入失败验证应用层行为。
