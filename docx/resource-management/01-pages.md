# 资源管理 · 页面拆解

[设计方案](design.md) · [PRD](00-prd.md) · [功能拆解](02-features.md) · [用户故事](03-user-stories.md) · [开发任务](04-development-tasks.md) · [测试用例](05-unit-test-cases.md) · [交互原型](prototype.html) · [文档维护规则](../development-standard.md)

覆盖环境管理、业务线管理、Kubernetes 集群与命名空间，以及监控诊断和资产数据源。环境与业务线采用当前平台目录交互，集群与数据源采用当前工作区及专项编辑流程。

## 环境与业务线目录

| 区域 | 环境管理 | 业务线管理 |
| --- | --- | --- |
| 标题及操作 | 环境管理及新增环境 | 业务线管理及新增业务线 |
| 目录切换 | 环境、业务线，显示已授权入口 | 同一套目录导航 |
| 工具栏 | 名称或 ID 搜索，目录顺序／名称／ID 排序 | 独立保留本页筛选 |
| 列表 | 环境名称、环境 ID、操作 | 业务线名称、业务线 ID、操作 |
| 右侧详情 | 名称、当前 ID、关联用途 | 名称、当前 ID、命名空间归属用途 |
| 新增及编辑 | 名称、ID，编辑时默认锁定 ID | 共用表单，显示业务线示例 |
| 删除弹窗 | 当前对象、确认、引用清单 | 支持集群／命名空间及角色引用 |
| 空态与权限 | 清空搜索、重新加载或显示只读 | 同一布局，使用业务线文案 |

表单头部、内容、底栏为独立区域。内容溢出时只滚动正文，底部放取消与保存。普通列表在 680px 及以下以条目排列。

## 集群与数据源工作区

| 页面区域 | 数据源管理 | Kubernetes 集群管理 |
| --- | --- | --- |
| 标题和主操作 | 数据源管理，新增数据源 | Kubernetes 集群管理，接入集群 |
| 视图切换 | 监控与诊断／资产数据源 | 集群列表／命名空间 |
| 摘要 | 已接入、需处理、暂停或停用 | 全部集群、需处理、等待采集 |
| 筛选 | 名称、环境、类型、状态；可按类型分组 | 集群名称、实例名称或 ID、环境、接入方式、状态；命名空间按名称、环境和实例 |
| 表格 | 名称与类型、所属范围、状态、最近活动、操作 | 集群与实例 ID、环境与业务线、接入方式、采集状态、节点状态、最近活动、操作 |
| 右侧详情 | 运行记录、连接与范围、快照或可见资产、操作 | 节点、命名空间、K8sGPT、最近检查或上报、重新校验 |
| 接入弹窗 | 类型选择，连接、范围预览或资产表单 | 方式选择，基本信息、连接与凭据、观测与诊断 |
| 其他 | 部署配置、资产游标、来源失败重试 | 命名空间归属、连接删除、重新连接、凭据轮换 |

在 680px 及以下宽度，列表按条目排列，操作保留在条目尾部。连接器测试、范围预览和保存使用固定底栏。集群编辑正文滚动，标题和操作可持续访问。列表在权限不足时仍保留合适的查看入口。

## 可观测数据源接入

连接器契约和部署配置见本节。列表布局与新增入口以集群与数据源工作区为准。

| 页面 | 区域 × 行为 |
| --- | --- |
| 资源管理／数据源管理 | Zabbix、Prometheus、VictoriaLogs、Alertmanager、Grafana 类型区和资产区。环境、状态筛选四类新连接，展开后维护。 |
| 接入或编辑弹窗 | 左侧名称、地址、认证，右侧授权范围与类型字段。连接成功后可预览，范围预览通过后可保存。窄屏纵向排列。 |
| 诊断总览 | 增加 Alertmanager 来源及活动或包含非活动过滤，覆盖提示、趋势和最近诊断同步反映当前范围。 |
| 故障与 K8sGPT 详情 | 共享既有指标、日志、告警证据区。范围匹配时附加 Grafana 仪表盘链接。 |

数据源在监控与诊断页签中配置。诊断结果、趋势和授权可见性见[诊断控制台](../diagnosis-console/design.md)。

| 页面／区域 | 交互和信息 | 对应需求 |
| --- | --- | --- |
| 数据源管理 | 标题「Zabbix 数据源」是折叠入口，接入按钮位于标题栏右侧。卡片展示名称、环境、业务、主机组、认证方式、问题数和最近成功时间。 | PRD-01、03、07、08 |
| 接入窗口 · 连接 | 从授权目录选择环境，填写名称和站点地址，再使用 API Token 或账号密码测试。成功后清除表单中的凭据。 | PRD-01、07 |
| 接入窗口 · 采集范围 | 显示左侧选择的环境和当前可选业务。搜索并勾选主机组后预览主机与问题。 | PRD-02、07 |

| Zabbix 问题详情 | 总览行展开后可看原始级别、确认状态、标签、持续时间，以及受控的原始问题链接。 | PRD-05 |

### 页面边界

页面包含独立路由和已有页面内的表单或分区。下表列的是页面能力，具体路由名在 Coding 阶段按 Portal 现有约定确定。

#### RM-P01

**Kubernetes 集群管理**<br>
入口 资源管理 → Kubernetes 集群管理，地址 `#/resources/clusters`

侧栏的「运维知识库」位于「诊断控制台」下方。

默认打开集群列表。资源管理导航、页面标题及列表标题均显示「Kubernetes 集群管理」。仅系统管理员可进入资源管理。列表展示集群名称、环境、业务线和接入状态，可展开采集详情。

显示无集群、读取失败及无权限状态。

功能 [RM-F01](02-features.md#rm-f01)、[RM-F02](02-features.md#rm-f02)

#### RM-P02

**接入及凭据配置**<br>
入口 P01 → 新增集群、配置连接、重新校验、轮换凭据

外部连接表单包含环境、集群名称、多选业务线、凭据方式及相应字段。本地连接提供归属补录。显示校验进度与失败原因。

按权限开放操作。校验失败可保存为待接入，轮换失败显示原因并继续使用原凭据。

功能 [RM-F02](02-features.md#rm-f02)、[RM-F03](02-features.md#rm-f03)、[RM-F04](02-features.md#rm-f04)、[RM-F16](02-features.md#rm-f16)

#### RM-P03

**采集状态与运行维护**<br>
入口 P01 → 集群采集状态

呈现首批节点、命名空间及诊断、最近成功采集时间、NotReady 节点、过期标志；在首次采集成功前允许修正集群环境。删除及重新连接按各自场景验收。

加载、无首批数据、部分数据、首次超时、节点过期和恢复等状态可区分。已删除本地记录呈现重新连接。

功能 [RM-F04](02-features.md#rm-f04)、[RM-F05](02-features.md#rm-f05)、[RM-F06](02-features.md#rm-f06)、[RM-F11](02-features.md#rm-f11)、[RM-F15](02-features.md#rm-f15)、[RM-F16](02-features.md#rm-f16)、[RM-F17](02-features.md#rm-f17)、[RM-F18](02-features.md#rm-f18)

#### RM-P04

**命名空间分配**<br>
入口 P03 → 命名空间分配

对命名空间多选业务线，显示已分配及待分配项，提供追加集群业务线的操作。

仅系统管理员可进入。零关联时进入待分配；保留已有连接和采集状态。

功能 [RM-F07](02-features.md#rm-f07)、[RM-F08](02-features.md#rm-f08)

#### RM-P05

**环境管理**<br>
入口 资源管理 → 环境管理

预置四个环境，提供新增、编辑名称与环境 ID、删除。授权在系统管理维护。

按操作权限显示按钮。删除引用冲突时列出相关集群。

功能 [RM-F09](02-features.md#rm-f09)、[RM-F10](02-features.md#rm-f10)

#### RM-P06

**业务线管理**<br>
入口 资源管理 → 业务线管理

跨环境业务线列表及维护操作。编辑弹窗支持修改名称和业务线 ID。显示删除阻塞所涉及的集群和命名空间。

系统管理员执行写操作，引用冲突时保留记录。

功能 [RM-F12](02-features.md#rm-f12)

#### RM-P07

**按环境查看诊断**<br>
入口 诊断控制台 → 环境 → 集群 → 命名空间

集群详情展示集群级诊断及已分配命名空间的诊断。命名空间详情仅展示当前命名空间的历史。

详情主体仅为历史诊断。按集群当前环境校验，直链执行相同校验。

功能 [RM-F08](02-features.md#rm-f08)、[RM-F13](02-features.md#rm-f13)、[RM-F15](02-features.md#rm-f15)

#### RM-P08

**按业务线查看诊断**<br>
入口 诊断控制台 → 业务线 → 集群 → 命名空间

集群详情展示当前业务线关联的命名空间诊断。命名空间详情展示该命名空间的完整历史。

详情主体仅为历史诊断。按当前环境和关联关系校验；集群级诊断从环境入口查看。

功能 [RM-F08](02-features.md#rm-f08)、[RM-F14](02-features.md#rm-f14)、[RM-F15](02-features.md#rm-f15)

### 页面评审边界

- RM-R01 · 三个资源管理子页、默认集群列表及待分配入口位置采用 PRD 评审方案。变更时同步修改页面映射。
- 节点列表和首批数据验证位于采集状态区。诊断控制台的详情主体只展示历史诊断。两处呈现的对象和查询权限各自按 PRD 执行。

页面交互参见 [资源管理原型](cluster-onboarding.html)。
