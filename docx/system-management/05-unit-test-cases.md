# 系统管理 · 测试用例

[设计方案](design.md) · [PRD](00-prd.md) · [页面拆解](01-pages.md) · [功能拆解](02-features.md) · [用户故事](03-user-stories.md) · [开发任务](04-development-tasks.md) · [交互原型](prototype.html) · [文档维护规则](../development-standard.md)

覆盖用户、用户组、角色与权限目录、LDAP/AD、登录会话、改密及操作审计。权限工作区按页面注册表派生名称、位置、顺序及旧名称搜索，接口权限编码与范围契约沿用服务端定义。

## 角色工作区与权限目录

### 工作区验收

| 场景 | 验收 |
| --- | --- |
| 数据源与集群入口 | 数据源管理属于资源管理的平台目录。集群能力按最新名称展示。权限操作编码和适用范围保持。 |
| 改名、跨模块移动 | 测试替换注册表节点名称和父级，菜单以及所有定位跟随更新。 |
| 快速授权 | 全局搜索后只勾选筛选内读取项，点击详情不影响勾选。跨筛选和跨角色保留草稿。 |
| 授权安全回归 | 预置和限制项禁止写入；混合范围分批处理；预览前不可提前提交；授权版本由原服务端保存逻辑验证。 |
| 窄屏 | 390px 下可点击权限复选框，键盘空格切换，主视口无横向滚动。 |

### 管理员组与权限点勾选验收用例

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| PC-TC21 | 超级管理员新建空组，勾选系统管理员并核对保存 | 显示当前成员 0 人，审计可定位；后续加入的 LDAP 员工登录获得系统管理员 |
| PC-TC22 | 已有组包含普通员工、直授管理员、其他组管理员 | 仅原普通员工重新登录才能获得权限，另外两人的会话仍有效；账号详情显示全部来源 |
| PC-TC23 | 撤销用户组管理员角色，随后重新授予 | 仅失去最后来源的账号会话失效，永久停用和待改密按原限制处理 |
| PC-TC24 | 普通管理员尝试新建、编辑、批量改角色、加入／移出管理员组，或操作继承管理员的账号 | 每条越权写入失败，批量正常条目仍可按原规则处理 |
| PC-TC25 | 获取影响预览后修改组成员，提交旧预览 | 返回冲突，权限、目标会话和组关系无部分写入。重新预览后可提交 |
| PC-TC26 | 在角色编辑器点击动作右侧可见的复选框，再点击动作名，使用空格切换复选框 | 勾选与详情独立，焦点停留在可操作控件。窄屏可在矩阵内滚动到对应列 |
| PC-TC27 | 先选择一个历史诊断动作，再筛选另一个动作并勾选或取消当前集合和结果，切换模块后返回 | 批量操作只影响匹配的可配置项，管理员专属项禁用，隐藏项保留，部分选择显示半选，空结果禁用批量控件 |
| PC-TC28 | 将同一动作添加到测试范围两次和生产范围一次 | 清单两条，敏感新增在确认页标记，只有确认保存后生效 |
| PC-TC29 | 勾选后直接尝试预览保存，或取消确认 | 未添加的勾选提示先加入清单，保存失败或取消时既有授权继续生效 |
| PC-TC30 | 角色列表加载时模拟接口目录不可用，打开角色编辑器并输入名称，再原地重试 | 名称和清单保留，重试成功后恢复每个动作右侧的复选框及批量工具 |
| PC-TC31 | 同时勾选资源范围和平台全局动作。选定测试环境并只加入资源范围，再加入平台全局。进入预览、返回编辑，再确认保存 | 第一次只加入资源范围，其他类型仍待添加。预览和返回编辑没有写请求，确认只提交一次，接口载荷与清单的权限点及数据范围一致，重新打开显示已保存 |
| PC-TC32 | 从角色列表新建角色，查看当前工作区，点击「保存角色」，按 Esc 或「返回编辑」，再次保存 | 草稿在当前页签展开，核对步骤使用弹窗。关闭核对后回到原工作区，已加清单和角色名称保留 |
| PC-TC33 | 通过真实 API 保存测试命名空间的单项读取授权。用已登录 LDAP 员工分别验证未关联、直授、组继承和最后来源撤销 | 未关联时请求拒绝；关联后同一会话允许测试范围读取，生产读取与未勾选的编辑动作仍受限制；撤销最后来源后立即拒绝 |
| PC-TC34 | 从系统管理侧栏点击「权限管理」，再依次进入「权限目录」和「返回权限配置」 | 首页直接显示角色草稿的复选框和授权清单，只读目录提供动作详情，返回后可以继续配置角色 |
