### 页面与状态

#### SM-P01

**用户管理**

- 入口 系统管理 → 用户管理
- 用户 系统管理员（含超级管理员）
- 内容 账号列表与搜索，按来源和状态筛选，单选或多选，进入用户详情。创建本地访客。选中操作栏右侧提供「删除用户」，仅对单个可删除的账号开放。确认弹窗展示目标及删除影响。创建或删除普通系统管理员仅超级管理员可执行。
- 状态 加载中；无账号或无匹配；查询失败可重试；逐项返回批量结果。
- 功能 [SM-F01](02-features.md#sm-f01)、[SM-F02](02-features.md#sm-f02)、[SM-F03](02-features.md#sm-f03)、[SM-F07](02-features.md#sm-f07)、[SM-F13](02-features.md#sm-f13)

#### SM-P02

**用户详情**

- 入口 SM-P01 → 账号详情
- 用户 系统管理员
- 内容 查看账号来源、状态、直接角色、用户组、实际生效权限与全部来源。按身份提供停用、启用、发放临时密码、授权或撤销。
- 布局 长 LDAP DN 自然换行。状态靠左、账号操作靠右。停用和删除采用危险描边，用户组与直接角色按整行对齐，关联标签自动换行，分配入口位于详情标题区。
- 状态 权限列表空态与停用态分开；错误保留原关系；失去当前授权时操作按钮和 API 均拒绝。
- 功能 [SM-F02](02-features.md#sm-f02)、[SM-F03](02-features.md#sm-f03)、[SM-F08](02-features.md#sm-f08)、[SM-F13](02-features.md#sm-f13)、[SM-F14](02-features.md#sm-f14)

#### SM-P03

**认证配置**

- 入口 系统管理 → 认证配置，地址 `#/admin/ldap`。
- 用户 本地超级管理员、普通系统管理员。首次登录待改密时进入改密流程。
- 外框 沿用全站原型：约 60px 深色顶栏、208px 白色侧栏、浅灰蓝工作区。侧栏浅蓝高亮认证配置，主区显示「认证配置」及「系统管理 › 认证配置」面包屑。窄屏可通过「栏目」按钮展开侧栏。
- 登录会话 第一张白色折叠卡片，初次进入默认收起。标题栏显示「登录会话」、当前有效期及展开指示，保存成功后就地更新。鼠标点击或键盘操作均可切换状态。
- 展开内容 桌面左侧显示分钟输入、保存按钮和反馈，右侧显示生效范围。窄屏上下排列。普通管理员看到当前值、只读提示及生效范围。输入未变更或正在保存时禁用保存按钮。
- LDAP 连接配置 第二张独立折叠卡片，初次进入默认收起，标题显示配置状态。展开后，LDAP URL、搜索 DN、搜索密码和基础 DN 各占一行，用户与组搜索及 LDAPS 证书配置可单独展开。桌面并排显示连接参数与四阶段验证，窄屏上下排列。验证失败保留测试凭据并显示失败阶段，成功清空测试凭据并启用保存按钮。密码字段不回显。
- 异常 读取失败可重试。保存失败保留草稿及标题栏生效值。会话过期提示重新登录。权限不足按现有门禁处理。
- 功能 [SM-F06](02-features.md#sm-f06)、[SM-F21](02-features.md#sm-f21)

#### SM-P04

**角色列表与编辑**

- 入口 系统管理 → 权限管理，默认打开角色草稿，已有角色通过「角色列表」进入。
- 用户 系统管理员
- 内容 查看两个预置角色，创建和编辑自定义角色，勾选接口权限点，选择范围后加入清单，核对并确认保存。历史诊断范围可在同一编辑器维护。删除前检查引用。详见[权限目录页面拆解](01-pages.md#管理员组与权限点勾选)。
- 状态 预置角色仅查看；无可授权命名空间时禁止提交；有关联时列出阻塞对象。
- 功能 [SM-F09](02-features.md#sm-f09)、[SM-F10](02-features.md#sm-f10)、[SM-F12](02-features.md#sm-f12)

#### SM-P05

**用户组列表与编辑**

- 入口 系统管理 → 权限管理 → 用户组
- 用户 系统管理员
- 内容 维护平台用户组；在组详情批量关联或撤销角色；日常组成员分配从用户管理进入。
- 状态 无组或无成员；关联角色为空；删除阻塞显示成员和角色。
- 功能 [SM-F11](02-features.md#sm-f11)、[SM-F12](02-features.md#sm-f12)

#### SM-P06

**登录与强制改密**

- 入口 登录页 → 待改密
- 用户 本地账号、LDAP 员工，按账号状态进入
- 内容 区分本地与 LDAP 登录；临时密码会话强制先改密。日常本地改密入口位置待确认。
- 状态 认证失败、已停用、目录暂不可用、会话失效与改密失败分别反馈；改密成功后进入身份对应首页。
- 功能 [SM-F04](02-features.md#sm-f04)、[SM-F05](02-features.md#sm-f05)、[SM-F07](02-features.md#sm-f07)、[SM-F08](02-features.md#sm-f08)

#### SM-P07

**操作审计**

- 入口 系统管理 → 操作审计
- 保留策略 低风险 3 天、中风险 5 天、高风险 7 天。超级管理员可分别设置保留天数，普通系统管理员可查看策略。
- 时间 列表和详情均以北京时间显示事件的实际时间，格式为 `2026年11月18日15:43:19`。
- 清理 天数按事件发生时间计算。超期记录随即停止展示，服务启动和每小时清理一次。保存策略时会立即清理超期记录。
- 用户 系统管理员
- 内容 按操作类型、风险等级、账号查询，查看变更结果、认证事件、自动撤权及批量逐项结果。
- 状态 无匹配、加载失败、失败原因脱敏。普通系统管理员可查看超级管理员创建和删除管理员的记录。
- 功能 [SM-F05](02-features.md#sm-f05)、[SM-F08](02-features.md#sm-f08)、[SM-F13](02-features.md#sm-f13)、[SM-F16](02-features.md#sm-f16)

#### SM-P08

**历史诊断**

- 入口 登录后 → 历史诊断
- 用户 拥有对应查看权限的访客、LDAP 员工或系统管理员
- 内容 按环境、集群、业务线及命名空间查看授权内记录；生产、预发布集群级诊断仅系统管理员可见。
- 状态 未授权数据从结果排除；无可查看范围、暂无数据和查询失败可区分；直接访问受后端验证。
- 功能 [SM-F14](02-features.md#sm-f14)、[SM-F15](02-features.md#sm-f15)

#### SM-P09

**集群所属环境**

- 入口 资源管理 → 集群详情
- 用户 系统管理员
- 内容 在首采成功前修正环境；节点状态或首条真实诊断任一成功即锁定环境。
- 状态 待采集可编辑；锁定显示当前环境；并发锁定后保存失败时提示刷新。
- 功能 [SM-F17](02-features.md#sm-f17)

页面交互参见 [系统管理原型](admin-workspace.html)。
