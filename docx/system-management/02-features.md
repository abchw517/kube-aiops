## 角色工作区与权限目录

### 当前功能

| 功能 | 规则 |
| --- | --- |
| 页面投影 | 菜单和目录查询同一注册表。改名、跨模块移动和排序变化不改变提交编码。 |
| 勾选 | 删除矩阵的空单元格。支持独立勾选、模块与组过滤、动作类型筛选、勾选当前读取及组内批量。不可委派项保持禁用。 |
| 草稿 | 筛选、模块切换及在角色工作区切换角色时保留进行中的草稿。确认前不发送更新。 |
| 异常 | 未映射能力显示未关联页面；目录失败保留原授权，重试后继续编辑。 |

### 管理员组与权限点勾选功能

角色选择以工作区的动作列表为准。下列勾选、范围和确认规则也用于旧版矩阵的兼容验收。

| 编号 | 功能 | 验收规则 |
| --- | --- | --- |
| PC-F11 | 用户组关联预置管理员 | 仅超级管理员可关联、撤销及维护管理员组成员。本地账号仍使用固定角色 |
| PC-F12 | 管理员角色并集与会话更新 | 直授和多个组来源去重；仅在有效管理员角色变化时更新会话版本。显示保留来源 |
| PC-F13 | 实时影响预览与审计 | 读取当前组、成员状态和角色来源；事务中重新核验预览；角色、会话和审计原子提交 |
| PC-F14 | 独立选择控件 | 角色工作区展示按业务页面分组的接口动作。每个可配置动作的复选框支持点击和键盘操作。名称打开详情，受限动作禁用。目录失败可在角色编辑器内重试 |
| PC-F15 | 范围限定批量勾选 | 当前集合和当前结果按可见、可配置动作计算全选或半选，空结果禁用批量控件。切换筛选和模块保留其他选择 |
| PC-F16 | 授权清单与保存 | 混合范围时按用户明确选择的类型分次加入清单，其余勾选保留。按接口动作及范围去重，可撤销清单条目。确认保存成功后在下一次接口请求中按新授权判定 |

### 功能与权限边界

脚本、轮询和会话等后台能力通过对应页面或审计反馈追踪。

#### SM-F01

**系统初始化和管理员管理** · PRD §2、§3、§4.2 · 页面 [SM-P01](01-pages.md#sm-p01)

- 操作者 超级管理员
- 操作目标 初始化时获得唯一账号，并管理多个普通管理员。
- 触发与输入 初始化与管理员写服务，原子维护唯一身份和会话撤销，区分普通与超级管理员。
- 输出与规则 并发初始化仍只有一个超级管理员；只有超级管理员可创建或删除普通管理员；删除后立即拒绝旧会话且产生审计；超级管理员不可删除。
- 用户故事 [SM-US01](03-user-stories.md#sm-us01)

#### SM-F02

**访客创建、停用和恢复** · PRD §2、§3、§4.2 · 页面 [SM-P01](01-pages.md#sm-p01)、[SM-P02](01-pages.md#sm-p02)

- 操作者 系统管理员
- 操作目标 发放临时密码并管理访客的访问生命周期。
- 触发与输入 访客创建及状态更新服务，保留关联角色；用统一撤销机制处理停用。
- 输出与规则 新访客关联固定只读角色；停用立即阻断登录和旧会话；恢复沿用原角色且不复活旧会话；系统管理员可从列表删除访客或 LDAP 员工。删除清除关联、使会话失效并写入审计，已删除的 LDAP 身份无法再次自动登记。
- 用户故事 [SM-US02](03-user-stories.md#sm-us02)

#### SM-F03

**搜索用户与账号详情** · PRD §3 · 页面 [SM-P01](01-pages.md#sm-p01)、[SM-P02](01-pages.md#sm-p02)

- 操作者 系统管理员
- 操作目标 定位用户和查看管理入口。
- 触发与输入 提供账号列表、详情读接口和统一查询投影；权限判断复用管理员身份。
- 输出与规则 列表可按账号及名称搜索并按来源、状态筛选；详情展示关系与实际状态；按钮和接口均按操作权限校验。
- 用户故事 [SM-US03](03-user-stories.md#sm-us03)

#### SM-F04

**本地临时密码与改密门禁** · PRD §2、§4.2 · 页面 [SM-P06](01-pages.md#sm-p06)

- 操作者 本地账号持有人及系统管理员
- 操作目标 使用临时密码安全完成首次登录或访客密码重置。
- 触发与输入 实现待改密状态、密码哈希更新、会话限制和旧凭据撤销。普通管理员建号和重置策略待评审。
- 输出与规则 待改密会话仅能执行改密相关操作；重置访客密码立即撤销旧会话；LDAP 密码在目录侧处理。
- 用户故事 [SM-US04](03-user-stories.md#sm-us04)

#### SM-F05

**超级管理员服务器恢复** · PRD §2、§4.2、§7 · 页面 [SM-P06](01-pages.md#sm-p06)、[SM-P07](01-pages.md#sm-p07)

- 操作者 部署运维
- 操作目标 在遗忘密码时恢复唯一超级管理员。
- 触发与输入 提供受服务器权限控制的 CLI/脚本入口，调用密码服务与审计；确认失败不能产生半成功状态。
- 输出与规则 专用脚本只重置超级管理员并发放临时密码；旧会话立即失效；完成改密后才允许管理；记录恢复事件且无密码明文。
- 用户故事 [SM-US05](03-user-stories.md#sm-us05)

#### SM-F06

LDAP 连接配置分为常用连接参数、可折叠的用户与组搜索和证书说明、四步验证及底部保存区。测试失败保留员工输入以便重试，配置变化使旧验证失效。

- LDAP 连接显式区分明文直连与校验证书的 LDAPS。目录连接结果区分 DNS、TCP、TLS 握手和证书校验。失败保留当前测试凭据，成功清空。验证和保存绑定同一草稿，验证有效期为五分钟。
- 配置及搜索密码写入 SQLite，默认无需密钥。已有密文可用原密钥读取，缺密钥时重新验证并保存。测试员工凭据不持久化。

**LDAP 草稿四阶段测试和启用** · PRD §4.1 · 页面 [SM-P03](01-pages.md#sm-p03)

- 操作者 系统管理员
- 操作目标 验证新配置，同时保留原线上登录配置。
- 触发与输入 复用 LDAP 客户端和凭据存储，引入草稿版本绑定及四阶段测试输出；校验测试和启用操作并发。
- 输出与规则 连接、绑定、查找指定员工、本人认证依次通过才可启用；测试不创建用户、会话或角色；草稿改动需复测；失败继续使用原配置。
- 用户故事 [SM-US06](03-user-stories.md#sm-us06)

#### SM-F07

**LDAP 首次登记与默认角色** · PRD §2、§4.3、§5 · 页面 [SM-P06](01-pages.md#sm-p06)、[SM-P01](01-pages.md#sm-p01)

- 操作者 LDAP 员工
- 操作目标 首次登录即可只读查看研发、测试诊断。
- 触发与输入 正式登录分支原子完成账号登记、判断有效角色与补发默认角色，测试登录共用认证但跳过持久化。
- 输出与规则 首次正式登录建立用户和默认角色；重复或并发登录不重复登记；仍有其他角色时保留默认角色撤销结果；失去最后一个角色时下次正式登录恢复默认角色。
- 用户故事 [SM-US07](03-user-stories.md#sm-us07)

#### SM-F08

**平台停用与 LDAP 目录状态** · PRD §4.3、§7 · 页面 [SM-P02](01-pages.md#sm-p02)、[SM-P06](01-pages.md#sm-p06)、[SM-P07](01-pages.md#sm-p07)

- 操作者 系统管理员或系统调度
- 操作目标 及时收回被停用员工的已有访问。
- 触发与输入 实现两侧独立状态和调度探针；区分已确认停用与目录不可用，注入时钟，禁止滑动延长故障期间会话。
- 输出与规则 平台停用立即失效；目录可用时停用后 5 分钟内撤销全部会话；目录故障时保留会话原定到期时间，恢复后补查；双侧启用才允许登录并沿用原授权。
- 用户故事 [SM-US08](03-user-stories.md#sm-us08)

#### SM-F09

**预置角色保护** · PRD §2、§5.1、§5.2 · 页面 [SM-P04](01-pages.md#sm-p04)

- 操作者 系统管理员
- 操作目标 查看预置角色且避免误改或误删。
- 触发与输入 在写服务和持久化入口保持保留角色标识，拒绝删除、编辑和跨身份授权。
- 输出与规则 预置权限固定，不为 LDAP 员工授予系统管理员角色；即使没有任何账号关联也禁止删除两个预置角色。
- 用户故事 [SM-US09](03-user-stories.md#sm-us09)

#### SM-F10

**自定义角色与历史诊断范围** · PRD §5.1 · 页面 [SM-P04](01-pages.md#sm-p04)

- 操作者 系统管理员
- 操作目标 按环境和资源归属授予诊断查看。
- 触发与输入 构建授权范围类型与验证器，使用资源目录稳定标识和当前归属，验证独立与共用集群。
- 输出与规则 只支持历史诊断查看；研测可选整个环境、集群或指定命名空间；预发生产要求明确业务命名空间；同角色可组合多个环境权限项。

#### SM-F11

**平台用户组和批量角色绑定** · PRD §3、§5.2、§5.3 · 页面 [SM-P05](01-pages.md#sm-p05)

- 操作者 系统管理员

- 输出与规则 平台组由管理员维护，LDAP 目录组变更不自动加组；可对一个组批量添加或移除角色；组员仅 LDAP 员工。

#### SM-F12

**自定义角色和用户组删除保护** · PRD §5.2 · 页面 [SM-P04](01-pages.md#sm-p04)、[SM-P05](01-pages.md#sm-p05)

- 操作者 系统管理员
- 操作目标 知道需要解除哪些关联才能删除。

- 输出与规则 角色有直接用户或用户组引用则拒绝，用户组有成员或角色则拒绝；解除全部引用才可删除；列出阻塞对象。

#### SM-F13

**单人和批量授权或撤销** · PRD §3、§5、§5.3、§7 · 页面 [SM-P01](01-pages.md#sm-p01)、[SM-P02](01-pages.md#sm-p02)、[SM-P07](01-pages.md#sm-p07)

- 操作者 系统管理员
- 操作目标 从账号列表一次维护多人的直接角色与组关系。
- 触发与输入 实现批量逐项验证和结果，默认角色保护按操作完成后剩余角色判定；绑定持久化和审计遵循评审规则。
- 输出与规则 支持加入、移出、授予和撤销，符合条件的项目独立成功；每项可追踪；不可撤销唯一默认角色，也不能给本地用户分配平台组。

#### SM-F14

**权限并集与访问来源** · PRD §3、§5、§5.1 · 页面 [SM-P02](01-pages.md#sm-p02)、[SM-P08](01-pages.md#sm-p08)

- 操作目标 查看授权范围并解释为何当前可以访问。

- 输出与规则 对有效权限求并集，每项列出直接角色和各组继承来源；撤权即时生效，仍有一条独立有效路径时继续可访问。

#### SM-F18

**就地筛选和授权** · [SM-US18](03-user-stories.md#sm-us18)

**同一角色编辑器与范围预览** · [SM-US19](03-user-stories.md#sm-us19)

同一集群下可一次选多个命名空间。研测显式选择环境或集群级范围，预发布及生产逐个校验业务归属。重复的完整范围只计一次。保存前展示增加、移除、直接用户、用户组及去重涉及账号数。固定角色只读，冲突留在当前编辑流程。

#### SM-F20

**审计直达** · [SM-US20](03-user-stories.md#sm-us20)

#### SM-F21

**查看与设置登录会话有效期** · PRD §4.5 · 页面 [SM-P03](01-pages.md#sm-p03) · 开发 [SM-T21](04-development-tasks.md#sm-t21)

- 操作者 已完成改密的系统管理员均可查看，仅唯一的本地超级管理员可保存。LDAP 管理员属于只读用户。
- 输入与输出 单一全局字段 `sessionLifetimeMinutes`。默认 30，允许 5 至 480 的整数。读取返回当前值，保存成功返回已提交值。空值、小数、非数字及越界值拒绝写入。
- 触发 登录时通过身份校验后读取已提交的策略。新会话的服务端到期时间和 Cookie 生存时间使用同一值。保存设置无需重启，不续期或撤销现有会话。
- 异常 策略读取或写入失败时返回服务不可用。保存失败时保留草稿和当前有效期。身份失效时进入重新登录流程，登录后重新读取策略。
- 独立性 LDAP 验证与启用使用原有独立流程。SQLite 保存策略及审计，旧版文件配置模式沿用默认值。

## AI 服务管理

**SM-F90**

- `GET /api/v1/admin/ai-services` 返回试点服务状态、部署及 Portal 范围绑定和模型版本。对应 `POST` 的 `recheck`、`discover`、`save`、`publish` 分别用于检查 `/readyz`、核对 Holmes `/api/model`、保存草稿和发布。`discover-binding` 发现试点模型，`bind` 校验精确范围和别名后写 SQLite。请求只使用已部署的精确范围，版本冲突返回 409。服务就绪及别名存在仍需通过实际推理验证。
- `GET /api/v1/admin/ai-skills` 列出技能和当前审核者身份。对应 `POST` 的 `upload`、`manual`、`approve`、`disable` 处理送审、独立审核和停用。已启用技能按精确范围和关键词匹配，手册来源对当前请求复查知识库访问权限和发布版本。
- 管理接口要求管理员，写入校验同源并进入操作审计。模型提供商的服务地址、API Key 和工具授权由部署侧维护。
