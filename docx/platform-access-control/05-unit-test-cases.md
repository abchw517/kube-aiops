# 平台访问控制 · 测试用例

[PRD](00-prd.md) · [开发任务](04-development-tasks.md)

夹具覆盖超级管理员、本地及 LDAP 系统管理员、普通 LDAP、访客和现有显式策略账号。资源夹具使用研测实例与共享生产集群，包含相同命名空间名、多业务归属和目录异常。所有用例为实施验收设计。
