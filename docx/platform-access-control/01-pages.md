# 平台访问控制 · 页面拆解

[PRD](00-prd.md) · [原型](prototype.html) · [功能](02-features.md)

| 页面 | 入口与主要用户 | 内容及操作 | 状态与权限 | 功能 |
| --- | --- | --- | --- | --- |
| <a id="ac-p01"></a> AC-P01 用户权限 | 系统管理 → 用户管理 → 用户详情；管理员 | 账号状态、角色及组关系、生效权限和全部来源；进入模拟检查。 | 停用展示已收回，授权为空展示空态，管理员账号变更受超级管理员限制。 | [F01](02-features.md#ac-f01)、[F02](02-features.md#ac-f02) |
| <a id="ac-p02"></a> AC-P02 角色配置 | 系统管理 → 权限配置 → 角色；管理员 | 模块动作、范围级联、修改差异和影响范围；保存后更新版本。 | 预置角色只读，未知范围或业务线提示，冲突保留输入。 | [F03](02-features.md#ac-f03) |
| <a id="ac-p03"></a> AC-P03 用户组 | 系统管理 → 权限配置 → 用户组；管理员 | 管理成员和角色，展示关联摘要与逐项批量结果。 | 拒绝本地账号、管理员角色或仍被引用的删除。 | [F01](02-features.md#ac-f01) |
| <a id="ac-p04"></a> AC-P04 权限模拟 | 从用户详情进入；管理员 | 选择待检查的动作、用户与目标资源；展示允许、拒绝和命中来源。 | 账号失效、缺权限、范围移除和目录异常反馈可区分。 | [F02](02-features.md#ac-f02)、[F04](02-features.md#ac-f04) |
| <a id="ac-p05"></a> AC-P05 授权审计 | 系统管理 → 操作审计；管理员 | 按主体、模块和风险筛选，查看变更批次、前后差异和目标。 | 普通管理员只可查看保留策略；超级管理员可维护。无结果或失败可重试。 | [F06](02-features.md#ac-f06) |
| <a id="ac-p06"></a> AC-P06 模块权限呈现 | 诊断、Wiki、资源与系统管理的既有入口；所有已登录用户 | 展示可使用动作；代表性预览说明 Wiki 搜索、推荐和发布结果。资源写和全局审计仍受原管理员授权。 | 无进入权限、对象不可见、可见但业务状态限制区分。导航与后端检查一致。 | [F04](02-features.md#ac-f04)、[F05](02-features.md#ac-f05)、[F08](02-features.md#ac-f08) |

[F07 迁移](02-features.md#ac-f07) 为后台能力，迁移差异由运维部署报告提供。权限 PRD 沿用现有认证、资源及知识库页面，不重画无关流程。
