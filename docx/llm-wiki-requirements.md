# LLM Wiki 诊断闭环需求

依据 [集成设计](llm-wiki-integration.md)。首期面向 Portal，保留 K8sGPT Result CR 的原始内容。沿用多集群 Finding、资源授权、现场证据和 Engine 模型连接。由 kube-aiops 提供内嵌 Wiki 服务、存储及接口，从空库部署。

## 用户与权限

| 角色 | 操作 |
| --- | --- |
| 诊断读者 | 查看授权范围内的初步诊断、增强说明、已确认结论和可见的 Wiki 引用。 |
| 复核人员 | 在授权范围内发起 AI 对话、总结并编辑待确认结论。首期沿用现有 AI 复核授权。 |
| 知识发布人员 | 对指定 Finding 的草稿进行确认和发布，在授权范围内查看任务并操作失败重试或撤回。知识发布需单独授予权限。 |
| 平台管理员 | 管理持久卷备份、检索预算，查看初始化、同步及索引健康状态。 |

## 功能需求

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| WK-R01 | 接收 K8sGPT 初步诊断 | Portal 展示原始故障现象和说明。初步诊断、增强说明、待确认草稿、已确认结论可辨认，生成增强说明期间可读取初步诊断。 |
| WK-R02 | 检索知识并生成增强说明 | 每次生成先按 Finding 授权范围检索一轮 Wiki，再将初步说明、最多 5 条有效引用及可用现场证据交给 AI。输出包含引用版本和待验证事项。 |
| WK-R03 | 降级与重新分析 | 区分无匹配、检索不可用和模型失败。Wiki 降级时使用现有证据，模型失败时可读取初步诊断。授权用户可重新分析，保留已确认结论。 |
| WK-R04 | 一轮或多轮 AI 对话和总结 | 会话绑定增强说明版本及引用快照。用户可连续补充信息，点击总结后使用绑定说明及完整会话生成可预览、可编辑草稿。发送消息、总结、关闭或刷新均不发布知识。 |
| WK-R05 | 用户确认最终结论 | 发布人员预览结论及脱敏知识，确认指定草稿和原作用域。API 在同一事务保存结论、知识快照及同步任务。同一草稿重试复用任务，其他草稿竞争同一旧版本返回 409。 |
| WK-R06 | 同步并展示进度 | 页面提供待同步、已同步和待处理状态。索引确认可检索后才显示已同步。失败退避重试，达到上限可重新排队。Wiki 故障期间已确认结论仍可读取。 |
| WK-R07 | 知识复用、订正与撤回 | 每个故障生成一个稳定知识编号，包含现象、结论、证据摘要和验证建议。确认订正后发布新版本，旧任务不能覆盖新版本。撤回后从检索移除，保留审计及结论历史。 |
| WK-R08 | 多环境、多集群隔离 | 从已授权 Finding 派生授权域、环境、业务、集群实例、命名空间，Wiki 与 Portal 双重校验。作用域也用于缓存隔离。草稿、任务和引用须校验归属。 |

## 运行与安全要求

| 编号 | 要求 | 验收标准 |
| --- | --- | --- |
| WK-R09 | 脱敏和引用完整性 | 进入模型和 Wiki 的文本经过后端脱敏与长度约束。发布条目仅包含允许字段，过滤凭据、个人敏感信息和对话全文。服务端验证引用编号、版本及可见范围。 |
| WK-R10 | 限时、审计与可恢复性 | Wiki 检索默认 2 秒，生成任务同指纹并发合并。确认、同步、重试、撤回均可追溯，审计记录角色、目标、版本和结果。服务重启后通过任务租约继续处理。 |
| WK-R11 | 兼容与部署验收 | OpenAPI 与生成客户端一致。在测试集群使用内嵌 Wiki 和 K8sGPT 完成发布、检索复用、订正和撤回。 |
| WK-R12 | 自动初始化 | 首次部署由程序在现有 SQLite 持久卷创建 Wiki 表及索引并注册 API，空库可立即检索。升级与重启保留数据。Wiki 初始化失败时可识别降级。共用 SQLite 可用时保留原诊断详情。 |

## 运维知识库浏览与问答

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| WK-R13 | 导航与 Wiki 文档列表 | 「系统管理」下方有同级入口。进入后显示分页文档列表，可按需打开 AI 问答对话框。列表可组合筛选环境、业务线、类型，点击条目可查看授权文档版本。 |
| WK-R14 | 使用 Wiki 进行 AI 问答 | 对话框可关闭和重开，支持多轮追问，默认沿用列表筛选。回答以匹配的 Wiki 片段为依据，带可打开的版本引用。缺少依据、检索失败和模型失败有对应提示。 |
| WK-R15 | 问答和浏览的权限边界 | 列表、筛选项、分页总数、详情、问答和引用都按当前权限约束。切换筛选开启新会话。权限变化后重新校验会话上下文，撤回内容不再用于问答。问答不写入诊断或知识。 |

## 主动录入与远端同步

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| WK-R16 | 手工录入及文档导入 | 有权限的用户可录入正文或上传支持的文档。逐文件展示转换预览、可编辑字段和失败原因。确认后知识可在授权范围内检索。 |
| WK-R17 | 统一内容转换 | 从各入口提取 Markdown 正文和结构化元数据，保留事实和步骤。范围由后端授权，转换后校验、脱敏和限制大小。异常条目保留状态供修正。 |
| WK-R18 | 指定远端目录同步 | 管理员可配置公司自建 Wiki 的目录 URL、只读登录账号和密码、子目录范围和本地目标作用域，先测试连接与预览。可点击「立即同步」，也可启用定时同步并配置 Cron 和时区。通过校验的页面自动保存到内置 Wiki，可查看逐页结果并重试。 |
| WK-R19 | 幂等、版本和权限 | 重复上传、重复同步或重启恢复不重复建档。远端页面变更生成新版本，完整枚举后确认删除才标记缺失。校验来源及页面的目录归属，发布后可用于列表、问答及诊断增强。 |
| WK-R20 | 登录凭据与定时配置 | 新来源必须输入账号和密码。密码加密存储，支持更换，详情只显示配置状态。定时计划可启停并显示下次运行，重启后恢复。手动触发不受计划开关影响，同一来源同一身份重复触发只执行一次。 |
| WK-R21 | 按登录用户复用 Wiki 凭据 | 保存后绑定 Portal 用户及同步来源，重新登录后显示本人远端账号和密码配置状态，手动同步自动使用本人绑定。定时计划使用配置人绑定，撤销授权、停用账号或解除绑定时暂停。 |

交付顺序见 [任务拆分](llm-wiki-tasks.md)，逐项验证见 [测试用例](llm-wiki-test-cases.md)。
