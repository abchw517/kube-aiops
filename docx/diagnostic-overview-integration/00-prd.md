# PRD · 诊断总览融合与数据源导航

值班人员在一个总览查看本权限范围内的故障事件、K8sGPT 结果和 Zabbix 问题。资源管理员在资源目录统一配置接入。原有诊断结果、故障事件及诊断策略继续提供完整工作流。

| 需求 | 验收标准 |
| --- | --- |
| R1 统一统计 | 一个指标区、一个趋势、一个级别分布和一张最近记录表。1 条故障与 3 条独立 Finding 显示 4 条，明确关联的 Finding 不重复计数。 |
| R2 筛选与下钻 | 集群和级别驱动所有区块，最近表展示来源，进入两类详情后可恢复筛选。 |
| R3 数据源导航 | 资源管理侧栏展示入口，旧链接跳转并保留查询参数，既有权限、表单和数据保持兼容。 |
| R4 异常可辨识 | 空范围显示 0，失败、截断及无权限以覆盖状态呈现。登录失效回到登录。 |

## 总览布局验收

| 需求 | 验收标准 |
| --- | --- |
| R5 分析区前置 | 指标卡下方显示共享外框的趋势和严重度分布。桌面首屏可见分析卡和最近诊断入口，390 px 下图内可横滑。 |
| R6 趋势交互 | 默认近 7 天，支持 14 和 30 天。切换窗口只更新趋势，地址与详情回跳记住时间窗。点击和键盘均可读出单日与各来源数量。 |
| R7 级别与口径 | 分布展示数量及占当前范围的百分比。点击级别全页联动，重复选择清除级别。趋势按 UTC+8 首次发现日统计，区分可确认零新增与来源缺数。 |
