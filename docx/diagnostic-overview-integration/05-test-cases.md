# 测试用例

| 用例 | 操作与预期 |
| --- | --- |
| T01 计数与排序 | 混合故障、Finding，所有指标与分布共用记录集，最近按首次发现倒序且不超过五条。 |
| T02 关联 | 同实例 ID 归并，跨实例保留；级别过滤在归并之后；已归并故障按可见代表记录处理。 |
| T03 时间 | UTC 日边界正确；无有效首次发现时间不进入趋势。 |
| T04 覆盖 | 权限不足、请求失败、分页上限和空结果区分。401 恢复登录。 |
| T05 筛选与回链 | 查看故障或 Finding 详情，返回时集群、级别恢复。 |
| T06 数据源 | 旧地址跳转时保留游标，资源导航高亮，配置测试同步与资产查看可用。 |
| T07 窄屏与键盘 | 320px、390px、1440px、1920px 检查，窄屏展示记录卡且整页无横向溢出。 |
| T08 总数与趋势 | 3 条首次发现于第 8 天之前的警告仍显示于指标和列表。切换 14 天后趋势显示 3 条，总数和列表保持。 |
| T09 日期范围 | 日桶为 UTC。7、14、30 可用，非法参数恢复为 7 天；核对窗口首日与未来记录过滤。 |
| T10 详情回链 | 在 14 或 30 天视图进入故障及 Finding 详情。两条回链分别恢复实例、级别和时间窗。 |
| T11 覆盖与空态 | 模拟单源失败、全部失败及完整覆盖无新增，确认覆盖状态、结果区域与重试操作。 |
