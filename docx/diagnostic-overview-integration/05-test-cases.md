# 测试用例

| 用例 | 操作与预期 |
| --- | --- |
| T01 计数与排序 | 混合故障、Finding，所有指标与分布共用记录集，最近按首次发现倒序且不超过五条。Zabbix 问题纳入相同口径。 |
| T02 关联 | 同实例 ID 归并，跨实例保留；级别过滤在归并之后；已归并故障按可见代表记录处理。 |
| T03 时间 | UTC+8 日边界正确；无有效首次发现时间不进入趋势。 |
| T04 覆盖 | 权限不足、请求失败、分页上限和空结果区分。401 恢复登录。 |
| T05 筛选与回链 | 查看故障或 Finding 详情，返回时集群、级别恢复。 |
| T06 数据源 | 旧地址跳转时保留游标，资源导航高亮，配置测试同步与资产查看可用。 |
| T07 窄屏与键盘 | 320px、390px、1440px、1920px 检查，窄屏展示记录卡且整页无横向溢出。 |
| T08 总数与趋势 | 3 条首次发现于第 8 天之前的警告仍显示于指标和列表。切换 14 天后趋势显示 3 条，总数和列表保持。 |
| T09 日期范围 | 日桶为 UTC+8。7、14、30 可用，非法参数恢复为 7 天；核对窗口首日与未来记录过滤。 |
| T10 详情回链 | 在 14 或 30 天视图进入故障及 Finding 详情。两条回链分别恢复实例、级别和时间窗。 |
| T11 覆盖与空态 | 模拟单源失败、全部失败及完整覆盖无新增，确认覆盖状态、结果区域与重试操作。 |
| T12 首屏和捷径 | 1920×900、1440×900、1280×800 验证分析卡先于最近诊断，关注最近诊断标题和链接是否可见。点击捷径后焦点落在最近诊断标题。 |
| T13 柱体与日选择 | 柱体从零轴起，分段高度等于来源数量在公共量程的比例。点击、方向键、Home、End 可选零值日并保留可见焦点。 |
| T14 时间窗局部更新 | 由 7 切至 14／30 天，最近诊断 DOM 和范围指标保持，URL、筛选及详情回链同步。 |
| T15 严重度联动 | 计数为 1／1／1 时验证分布为 33.3%／33.3%／33.3%，在筛选至单级后验证 100.0% 条与零值空条，点击严重后近况清单联动，再点严重清除。 |
| T16 本地日界线 | `15:59:59Z` 和 `16:00:00Z` 分属 UTC+8 相邻日期。推迟一秒的未来记录只保留在当前范围计数中。 |

## 验证记录

本地 Web 类型检查、生产构建、37 项单元测试及 Chromium 端到端测试均通过。浏览器验证覆盖 1920 × 900、1440 × 900、1280 × 800、390 px 和 320 px，数据来自测试夹具。
