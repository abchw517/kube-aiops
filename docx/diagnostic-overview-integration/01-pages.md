# 页面拆解

| 页面 | 区域与交互 |
| --- | --- |
| 诊断总览 | 紧凑筛选和最近诊断捷径 → 四张指标卡 → 左侧趋势和右侧严重度分布组成的分析卡 → 最近五条与完整列表入口。 |
| 故障详情 | 展示故障真实状态，返回原总览时恢复完整查询条件。 |
| 原有诊断详情／结果 | 通过实例 ID 定位结果并保留回链，旧侧栏继续进入完整列表、筛选和分页。 |
| 数据源管理 | 列于资源管理的平台目录，沿用配置、编辑、连通测试、同步、资产和启停。 |

内容宽度不超过约 760 px 时，分布移到趋势下方。30 天允许绘图区内部滚动，两个坐标轴与日读数仍可用。窄屏最近记录切换为卡片。
