# kube-aiops 诊断总览 UI 重构设计

实施版 · 2026-11-24 · 基线 PR #116

## 当前页面和原型的差异

| 截图表现 | 代码与数据原因 | 设计调整 |
| --- | --- | --- |
| 两个下拉框和「应用筛选」各占约三分之一 | 总览复用了故障列表的等分表单网格 | 使用紧凑工具栏。筛选按钮按文字宽度排列，旁边提供清除。筛选结果直接显示在当前范围行。 |
| 趋势图留下大块空白，标题贴近卡片边缘 | 总览借用了故障页图表容器，零值仍预留完整绘图区 | 统一面板内边距和标题样式。窗口无记录时显示紧凑空态及明确日期范围，提供延长时间窗的入口。 |
| 级别分布有数值，但缺少视觉主次 | 现行页面只渲染级别图例列表 | 用比例条和独立的计数列表示分布。每一级同时显示标签与数值。 |
| 最近诊断排在图表之后，表格长字段挤占空间 | 页面按「筛选 → 指标 → 图表 → 最近诊断」排列 | 将最近诊断移到图表前。问题列占主要宽度，状态、来源、实例单独成列，窄屏用记录卡。 |

## 三层视角

| 视角 | 核心问题 | 重构决策 |
| --- | --- | --- |
| 运维专家 | 选定实例现在有什么问题，我下一步打开哪里？ | 首屏先展示当前范围、严重度数字和统一的最近诊断。故障和 K8sGPT 在同一张表中按首次发现倒序，来源清晰，状态仅在故障有对应状态时展示。 |
| 产品专家 | 总数和趋势为何看起来矛盾，切换筛选影响哪些数据？ | 明确数字卡是当前范围存量，趋势是该范围按首次发现时间划出的窗口子集。实例和级别联动全页；7／14／30 天只作用于趋势。保留两个明细页与筛选回链。 |
| 前端专家 | 如何让这页与 HTML 原型可逐项核对？ | 为总览定义独立工具栏、指标网格、记录列表和上下文图表布局。继续使用现有 Portal 外壳、颜色变量、焦点样式和服务端鉴权。将原型状态和视口尺寸固化为视觉回归用例。 |

## 页面布局

1. **页头与筛选工具栏**。保留模块导航、面包屑和「诊断总览」。页头下使用一行筛选，最大宽度控制在常用桌面视口内。显示已应用的实例、级别和来源覆盖状态。覆盖不足时展示独立提示及重试入口。
2. **统一指标**。一排四卡「诊断记录总数、严重、警告、信息」，窄屏两列。点击级别卡更新全页筛选，点击总数恢复全部级别。选中态同时使用边框、文字标识与语义状态。总数随筛选联动。
3. **最近诊断**。全宽优先展示最多 5 条合并后的记录。桌面字段为问题、级别、处置状态、来源、实例、首次发现。问题自然换行，ID 和时间列优先保持可读性。窄屏按「问题 → 级别与来源 → 实例、状态和时间」展示记录卡。点击问题进入本记录详情，返回恢复筛选和趋势窗。
4. **分析图表**。桌面趋势和级别分布使用约 2:1，两张卡在窄屏纵向排列。趋势采用 UTC 日桶，来源用双色堆叠，日期可用键盘选择读取计数。分布图展示当前范围级别数量。窗口无记录时趋势卡收起绘图区，只保留时间范围、空态和切换窗口。

## 口径与交互契约

| 状态 | 总览表现 |
| --- | --- |
| 截图场景 · 3 条警告均为 11 月 16 日发现 | 指标显示 3 条、警告 3，最近诊断立即可见。11 月 18 日至 24 日的 7 天趋势提示「近 7 天无新增」。切到 14 天后，11 月 16 日显示 3 条 K8sGPT；指标和最近记录保持原范围。 |
| 当前过滤后没有记录 | 四张指标卡显示 0，最近诊断提供清除筛选入口。趋势显示该条件下无新增。 |
| 单来源失败或分页覆盖不全 | 保留可用记录并标注「已获取」。趋势在无可用记录的窗口提示「数据覆盖不完整」；分布仅表示已获取结果。原有授权边界和归并规则兼容。 |
| 全部来源失败 | 保留筛选和重试，统计和图表用不可用状态。与真实的空结果区分。 |
| K8sGPT 结果已关联同实例故障 | 沿用 PR #116 的显式归并，故障代表记录参与统计。一条记录只出现在最近列表的一行。 |

当前趋势数据集仍基于可查询记录。扩大时间窗只增加日桶范围，历史已消失的 Finding 不会由此恢复。原型将统计日固定为 2026-11-24，使用脱敏样例验证截图场景。保留实例和级别筛选，新增 `trendDays=7|14|30` 作为可恢复的视图参数。

## 前端实施与验收

- 将总览的 DOM 与布局规则集中在 `unified-overview.ts` 及总览专用样式。复用 `aggregateDiagnostics` 的显式归并和排序逻辑，将日桶长度作为受限参数。现有接口和存储契约继续使用。
- 总览面板外间距 16px、内边距 16–20px、圆角 8–10px。主标题 26–28px，区块标题 16–18px，数值 26–30px。筛选按钮保持内容宽度，长问题串可安全断行。
- 在 1920×958、1440×900 和 390×844 对照同一组数据，验证筛选、数字卡、记录首行、图表标题与信息顺序。桌面在无需滚动即可看到最近记录，390px 不出现整页横向滚动。
- 验收 7 天空态与 14 天恢复绘图、混合来源堆叠、无记录、覆盖不完整、全部失败、级别卡筛选及明细返回。键盘测试覆盖筛选、日期选择及行链接。
