# 页面拆解

| 模块 | 页面或组件 | 页面布局 | 操作与状态 |
| --- | --- | --- | --- |
| 公共外框 | 主导航、模块侧栏、面包屑 | 顶栏识别模块，侧栏定位子页，内容区按阅读宽度居中 | 当前项、受限入口、跳过导航、窄屏栏目 |
| 登录 | 登录控制台 | 柔和背景与单列登录卡；账户、密码、认证方式、反馈、登录 | 本地默认，LDAP 可选，登录失败和会话约束沿用真实状态 |
| 诊断控制台 | 诊断总览 | 过滤器与当前范围、四色指标、趋势与严重度、近期记录 | 范围联动、7/14/30 天、日期读数、级别筛选、详情跳转 |
| 诊断控制台 | 故障事件、诊断结果、策略 | 紧凑筛选与表格，详情路由显示证据与处置 | 支持现有查询、分页、策略设置和返回上下文 |
| 资源管理 | Kubernetes 集群 | 顶部接入入口、列表／命名空间切换、结果表、详情侧栏 | 接入、归属、分区编辑、测试连接与凭据轮换 |
| 资源管理 | 数据源 | 监控与诊断／资产数据源切换、过滤器与状态表 | 按类型分组、详情、验证、采集范围预览和提交 |
| 资源管理 | 环境管理、业务线管理 | 页面标题、目录切换、过滤与列表、编辑弹窗 | 查询和复制 ID，重复、只读、引用冲突与空列表 |
| 运维知识库 | 知识检索、知识详情、知识治理 | 文档列表和正文、治理卡片与来源状态 | 关键词检索、版本引用、候选复核、来源和同步 |
| 系统管理 | 认证、用户、权限、审计、改密 | 认证表单卡、目录和数据表，操作结果与详情区 | 本地与 LDAP 会话、角色和用户组、权限目录、审计详情 |

资源和权限的可见栏目来自现行页面注册表。表格状态、弹窗分区和详情入口由当前页面实际数据驱动。
