# 功能拆解

| 编号 | 功能 | 规则 |
| --- | --- | --- |
| F-01 | 全局视觉语言 | 颜色、角半径、字号、阴影在 CSS 变量中定义；各工作区将主控件及容器映射到公共变量 |
| F-02 | 导航与焦点 | 使用已有可见菜单和活动路由计算；窄屏栏目展开时聚焦当前项，关闭后复位；直接访问保留原鉴权 |
| F-03 | 诊断趋势 | 真实数据按 UTC+8 首次发现日汇总，支持 7、14、30 日；宽屏尽量展示完整列，窄屏在图表容器内滚动 |
| F-04 | 严重度 | 环形图按已取得记录渲染；文字比例和数量由同一数据计算；未知级别留中性比例并提示，级别链接更新现有查询参数 |
| F-05 | 资源工作区 | 使用标签式视图切换、状态标签和列表；搜索及分组行为沿用既有接口；详情、编辑分工清晰 |
| F-06 | 表单交互 | 集群分基本信息、连接与凭据、观测与诊断；复选框水平对齐；Zabbix 支持先测试、再选采集范围和预览 |
| F-07 | 关闭与写入保护 | Zabbix 明确关闭按钮丢弃草稿，Esc 使用既有非主动丢弃防护；保存期间保持防止重复提交的逻辑；目录的冲突保护单独保留 |
| F-08 | 知识与系统 | 知识库、用户、角色、审计和认证使用共用面板和控件，保留查询、审计留存和账号安全策略 |
| F-09 | 反馈 | 已加载、空结果、部分不可用、失败、正在保存和无权限仍由实际状态驱动；关键状态有可读文本 |
