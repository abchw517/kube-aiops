# PRD · 全局布局与可读性

## 目标与使用对象

值班工程师能从诊断总览快速找到风险与记录，平台管理员能在资源和系统配置之间保持一致的操作方式，研发读者能通过知识库和现有诊断链接快速定位内容。

## 需求与验收

| 编号 | 优先级 | 需求 | 验收条件 |
| --- | --- | --- | --- |
| PR-01 | P0 | 统一主导航、模块侧栏和页首 | 四个模块使用白色顶栏与圆角选中态；面包屑、当前页面与权限匹配；移动端栏目支持键盘打开、关闭和跳转 |
| PR-02 | P0 | 提升字号和视觉层级 | 正文基准 16 px，主要表格单元格和输入 15 px；卡片与弹窗在视觉上能一眼区分；320–1920 px 宽度检查无整页横向溢出 |
| PR-03 | P0 | 优化诊断总览 | 范围、指标、趋势与严重度、最近记录依次可读；7、14、30 天图表与每日明细、筛选、部分可用和重试状态可操作 |
| PR-04 | P0 | 统一资源工作区和配置表单 | 集群、数据源、环境和业务线的页面标题、列表和详情风格一致；复选框及文字同行；Zabbix 点击「取消」或「×」直接关闭，重开时使用新表单 |
| PR-05 | P0 | 完成知识库、系统管理和登录页视觉覆盖 | 知识文档、权限目录、用户、审计、认证、登录页使用同套视觉规则；本地与 LDAP 登录选择、强制改密和审计入口可用 |
| PR-06 | P0 | 保持配置和权限操作可靠 | 表单仍按原规则验证，提交中遵循原保护；现有路由、查询和 API 合约继续得到回归验证 |
| PR-07 | P1 | 支持小屏与辅助操作 | 宽表可在组件内滚动，状态含文本；日期可通过方向键、Home、End 查阅，键盘可从表单返回触发点 |

交付边界为 Portal 的布局、类型样式与真实页面交互。原型示例只用于设计验证，产品读写、认证及审计由已有服务端接口承担。
