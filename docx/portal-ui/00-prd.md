# kube-aiops 全站 UI 改版 PRD

## 目标与范围

四个模块统一使用共享工作区。顶栏切换模块，侧栏切换栏目，面包屑显示当前位置。资源范围树在页面内筛选数据。

本期适配诊断控制台、资源管理、运维知识库和系统管理。诊断总览展示核心指标、趋势、级别分布与最近故障。Kubernetes 集群管理提供范围树、集群列表及命名空间。知识库保留检索、详情、问答和治理，系统管理保留现有表单、权限与审计。

以[全站 UI 设计说明](../portal-ui-design.html)和[可交互原型](../portal-ui-prototype.html)为视觉基线。部署后使用真实服务端数据。认证配置继续遵循已确认的登录会话专项方案。

| 项目 | 验收标准 |
| --- | --- |
| 导航 | 四模块按现有能力显示，选中态与路由一致，旧链接与详情返回地址可用。 |
| 诊断 | 值班人员无需展开筛选即可核对查询范围。总览按范围、值班指标、最近故障和趋势排列。待确认、处理中、高风险（P1）、已恢复指标可进入对应故障列表，保留相容筛选。缺失计数、零件故障和读取失败分别显示。 |
| 资源 | 资源管理入口、页面标题和集群列表区标题统一为「Kubernetes 集群管理」。范围树及两种列表使用授权数据，点击任意环境名称，直接显示该环境下的全部可见集群。范围树仅在顶层保留「全部集群」。 |
| 知识库 | 保留搜索、分页、详情与按权限显示的问答、草稿和治理入口。 |
| 系统管理 | 侧栏「权限管理」直接打开角色授权矩阵。按 PR #111 原型支持逐项、按工具集合及当前筛选批量勾选，选择范围后加入授权清单，核对并确认保存。存量角色从「角色列表」编辑，顶部「权限配置」按钮进入只读权限目录。LDAP 连接参数与四步验证分区展示，长 URL、DN 独占行，明文 LDAP 复选框与说明文字同排居中，四步通过后方可启用。登录会话和 LDAP 默认折叠，只有本地超管能保存会话策略。 |
| 响应式 | 桌面显示完整侧栏。窄屏展开栏目时聚焦当前栏目，按 Escape 收起并返回触发按钮。宽表在其容器内滚动。 |

用户身份、API 授权、数据校验和审计规则沿用现有模块定义。参见[系统管理 PRD](../system-management/00-prd.md)、[资源管理 PRD](../resource-management/00-prd.md)和[权限目录 PRD](../permission-catalog/00-prd.md)。
