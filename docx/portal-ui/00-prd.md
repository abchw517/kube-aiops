# kube-aiops 全站 UI 改版 PRD

## 目标与范围

四个模块统一使用共享工作区。顶栏切换模块，侧栏切换栏目，面包屑显示当前位置。资源范围树在页面内筛选数据。

本期适配诊断控制台、资源管理、运维知识库和系统管理。诊断总览展示核心指标、趋势、级别分布与最近故障。集群接入提供范围树、集群列表及命名空间。知识库保留检索、详情、问答和治理，系统管理保留现有表单、权限与审计。

以[全站 UI 设计说明](../portal-ui-design.html)和[可交互原型](../portal-ui-prototype.html)为视觉基线。部署后使用真实服务端数据。认证配置继续遵循已确认的登录会话专项方案。

| 项目 | 验收标准 |
| --- | --- |
| 导航 | 四模块按现有能力显示，选中态与路由一致，旧链接与详情返回地址可用。 |
| 诊断 | 指标、趋势、级别分布与列表对应相同的有效查询范围，区分无数据与失败。 |
| 资源 | 范围树及两种列表使用授权数据，环境和集群切换同步过滤。 |
| 知识库 | 保留搜索、分页、详情与按权限显示的问答、草稿和治理入口。 |
| 系统管理 | 保留用户、角色、组、审计及改密。「权限管理」维护角色和用户组，其「权限配置」入口打开接口矩阵。登录会话和 LDAP 默认折叠，只有本地超管能保存会话策略。 |
| 响应式 | 桌面显示完整侧栏，窄屏可展开栏目，焦点可见，宽表在其容器内滚动。 |

用户身份、API 授权、数据校验和审计规则沿用现有模块定义。参见[系统管理 PRD](../system-management/00-prd.md)、[资源管理 PRD](../resource-management/00-prd.md)和[权限目录 PRD](../permission-catalog/00-prd.md)。
