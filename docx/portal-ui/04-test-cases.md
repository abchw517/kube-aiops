# 全站 UI · 测试用例

桌面以 1440px 对照原型，窄屏采用 390px 和 320px。分别用管理员、受限用户及已过期会话验证，浏览器可用固定接口响应提供可重复的数据。

| 用例 | 操作或夹具 | 预期 |
| --- | --- | --- |
| UI-UT01 | 依次打开四模块及各自子页 | 顶栏、侧栏、面包屑和正文指向同一页面。 |
| UI-UT02 | 直接打开原列表、详情、权限子页，刷新和前进后退 | 原链接可用，原有筛选和返回参数保留。 |
| UI-UT03 | 受限账户浏览并直接访问受限 URL | 菜单与操作按能力显示，接口拒绝时显示受限状态。 |
| UI-UT04 | 1440px 下对照诊断总览 | 顶栏、侧栏、工作区及指标、图表、列表的视觉层级符合原型。 |
| UI-UT05 | 准备多个日期和级别的故障数据，切换查询范围 | 指标、分布、趋势及近期列表数据一致。部分数据标明统计范围。 |
| UI-UT06 | 进入故障详情、拓扑及 AI 分析后返回 | 已授权内容可达，列表筛选按返回链接恢复。 |
| UI-UT07 | 打开 Kubernetes 集群管理，选择全部、环境、集群，切换命名空间并搜索 | 侧栏、页面及列表标题统一，树仅展示授权节点，两个视图与所选范围一致。 |
| UI-UT08 | 模拟命名空间空结果、采集失败及直接打开集群详情 | 空结果和失败可区分，管理操作沿用现有权限。 |
| UI-UT09 | 知识库搜索、分页、开详情，切换问答与治理权限 | 搜索、分页与详情可用，操作随能力显示。 |
| UI-UT10 | 查看认证配置，分别用超管、普通管理员展开并操作 | 两卡默认收起，标题显示值，仅超管能保存会话，LDAP 验证和启用可用。 |
| UI-UT11 | 完成已有用户、角色或 LDAP 操作并查看审计 | 原操作及审计规则生效，切换视图无需重复提交。 |
| UI-UT12 | 模拟加载、无匹配、服务失败、401 与 403 | 各状态可区分。过期要求登录，403 显示无权限。失败保留适用上下文。 |
| UI-UT13 | 390px 和 320px 展开栏目、资源范围与认证卡片 | 栏目可达，内容换行，页面无横向溢出，宽表在容器内滚动。 |
| UI-UT14 | 用键盘切换模块、折叠区和列表，打开并关闭弹窗 | 焦点可见，交互控件有名称并暴露状态，可跳至主内容。 |
| UI-UT15 | 从侧栏「权限管理」进入，逐项或批量勾选，筛选后加入授权清单并确认保存 | 直接显示可编辑矩阵。隐藏项保留，受限项不可勾选，确认提交后可在角色列表回查。只读「权限目录」提供返回权限配置入口。 |
| UI-UT16 | 在 1440px 和 390px 展开 LDAP 卡片。依次触发失败、成功、修改配置、重新验证和保存 | URL、DN 与员工字段标签独立，页面无横向溢出。失败时保存禁用，成功后清空测试凭据并启用保存，配置变化使验证结果失效。 |

会话策略范围、SQLite 迁移、会话签发及审计另按[系统管理专项用例](../system-management/05-unit-test-cases.md#sm-ut21)验证。
