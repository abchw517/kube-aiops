# 前端 UI · 测试用例

[设计方案](design.md) · [PRD](00-prd.md) · [页面拆解](01-pages.md) · [功能拆解](02-features.md) · [用户故事](03-user-stories.md) · [开发任务](04-development-tasks.md) · [交互原型](prototype.html) · [文档维护规则](../development-standard.md)

全站外框、导航、视觉和登录是本模块的维护范围。业务页面流程分别维护在对应模块中。当前以全站白色布局与最新登录背景为准。

## 登录页

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| DWL-TC-09 | 桌面及 390 px 窄屏访问未登录页 | 背景与输入明确分层、无水平溢出，LDAP 与文字在同一行 |
| DWL-TC-10 | 本地与 LDAP 登录、校验失败和会话过期 | 原有实际认证流程和消息正常，登录完成后卸载装饰 |

## 全站布局与共享工作区

| 编号 | 条件与操作 | 预期 | 检查方式 |
| --- | --- | --- | --- |
| TC-01 | 以完整权限打开集群管理，检查导航、标题、输入与卡片 | 16 px 正文、15 px 输入、12 px 控件和 20 px 卡片圆角生效；模块选中态清晰 | 浏览器 |
| TC-02 | 320 或 390 px 打开诊断和资源页面，使用键盘展开栏目、Esc 关闭并重新进入子页 | 无整页横向滚动；关闭返还焦点，跳转后聚焦内容 | 浏览器 |
| TC-03 | 未认证打开工作区，分别使用本地账号和 LDAP 登录，再退出 | 登录表单含认证方式，默认本地；已有认证、退出和强制改密状态可用 | 单元测试、浏览器 |
| TC-04 | 有近期数据时切换 7、14、30 天，点柱形或使用方向键 | 柱形高度随真实数据，同日读数更新；桌面无图表横向滚动，窄屏只在图表内部滚动 | 浏览器 |
| TC-05 | 选择某一严重度，校验环图、比例和范围；验证 CSP | 图形层的分割比例与文字一致，点击使用原筛选链接，未知级别显示中性比例和说明 | 单元测试、浏览器 |
| TC-06 | 模拟仅有较早记录、部分来源失败或全部失败，点重试 | 空窗口、部分可用、暂不可用和重试各自明确，既有历史记录可在范围内查看 | 浏览器 |
| TC-07 | 在 1280 与 390 px 分别进入集群基本信息和观测与诊断，点击复选框文案 | 复选框与标签垂直居中、相邻同行，文案可切换勾选且默认值正确 | 浏览器 |
| TC-08 | 在 1100 与 390 px 打开 Zabbix；切换认证、测试和预览；填充后分别点取消及 × | 24 px 弹窗圆角，宽屏并排、窄屏单列，操作区可见；直接关闭且重开没有旧草稿 | 浏览器 |
| TC-09 | 查询、编辑名称、修改目录 ID，触发重复或引用冲突 | 保持现有业务规则，列表、空态、焦点、冲突说明和复制入口可用 | 单元测试、浏览器 |
| TC-10 | 检索知识、打开详情、查看候选复核或同步结果 | 正文可读，授权范围与反馈、来源、版本链接可用 | 浏览器 |
| TC-11 | 切换角色、用户组、权限目录与审计过滤，使用无权限账号直接访问 | 角色范围、审计详情和授权拦截与现有业务一致 | 单元测试、浏览器 |
| TC-12 | 在 1920、1440、1280、390、320 px 校验诊断总览 | 桌面图表双卡并排且显示近期诊断标题；窄屏堆叠、记录卡和图表滚动分区正确 | 浏览器 |

执行入口为 `make web-check` 和 `make web-e2e`。浏览器回归使用仓库 mock 服务验证实际 Portal 前端与服务接口契约。

## 共享导航回归

| 用例 | 操作或夹具 | 预期 |
| --- | --- | --- |
| UI-UT01 | 依次打开四模块及各自子页 | 顶栏、侧栏、面包屑和正文指向同一页面。 |
| UI-UT02 | 直接打开原列表、详情、权限子页，刷新和前进后退 | 原链接可用，原有筛选和返回参数保留。 |
| UI-UT03 | 受限账户浏览并直接访问受限 URL | 菜单与操作按能力显示，接口拒绝时显示受限状态。 |
| UI-UT09 | 知识库搜索、分页、开详情，切换问答与治理权限 | 搜索、分页与详情可用，操作随能力显示。 |
| UI-UT10 | 查看认证配置，分别用超管、普通管理员展开并操作 | 两卡默认收起，标题显示值，仅超管能保存会话，LDAP 验证和启用可用。 |
| UI-UT11 | 完成已有用户、角色或 LDAP 操作并查看审计 | 原操作及审计规则生效，切换视图无需重复提交。 |
| UI-UT12 | 模拟加载、无匹配、服务失败、401 与 403 | 各状态可区分。过期要求登录，403 显示无权限。失败保留适用上下文。 |
| UI-UT13 | 390px 和 320px 展开栏目、资源范围与认证卡片 | 栏目可达，内容换行，页面无横向溢出，宽表在容器内滚动。 |
| UI-UT14 | 用键盘切换模块、折叠区和列表，打开并关闭弹窗 | 焦点可见，交互控件有名称并暴露状态，可跳至主内容。 |
| UI-UT16 | 在 1440px 和 390px 展开 LDAP 卡片。依次触发失败、成功、修改配置、重新验证和保存 | URL、DN 与员工字段标签独立。明文 LDAP 复选框与标签文字同一行、垂直居中，点击标签文字可切换复选框。页面无横向溢出。失败时保存禁用，成功后清空测试凭据并启用保存，配置变化使验证结果失效。 |
