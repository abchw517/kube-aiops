全站外框、导航、视觉和登录是本模块的维护范围。业务页面流程分别维护在对应模块中。当前以全站白色布局与最新登录背景为准。

## 登录页

| 用户 | 情境 | 可验收结果 |
| --- | --- | --- |
| LDAP 用户 | 从窄屏进入控制台 | 背景与卡片有清晰反差，LDAP 选项与文案同行，校验和登录反馈仍可读 |

## 全站布局与共享工作区

| 故事 | 用户目标 | 验收场景 |
| --- | --- | --- |
| US-01 | 作为值班工程师，我希望在同一屏先看到严重数量和诊断趋势 | 打开诊断总览后先看到筛选与指标，切换 30 天仍可查看数据坐标，近期记录位于分析区下方 |
| US-02 | 作为值班工程师，我希望确认某天主要告警来自哪个来源 | 点击图柱或用方向键移动，日期和各来源的文字读数同步更新；最近记录仍按原先筛选口径显示 |
| US-03 | 作为集群管理员，我希望更轻松地修改名称与观测配置 | 打开配置，分区可独立浏览，标签与复选框同行；连接测试和保存键在窄屏上仍可到达 |
| US-04 | 作为数据源维护者，我希望在尝试连接失败或暂不接入时快速返回列表 | 填写后点「取消」或「×」即可关闭 Zabbix 表单，重新打开时看不到前一次名称和凭据 |
| US-05 | 作为研发人员，我希望在小屏查阅诊断记录和知识文档 | 通过栏目菜单到达目标页；记录卡显示关键信息；知识检索及文档内容可阅读 |
| US-06 | 作为审计员，我希望能清楚区分控件、结果与明细 | 审计筛选、记录与详情各有层级，现有角色只看到本人获准的操作 |
| US-07 | 作为通过 AD 登录的员工，我希望一眼找到认证方式 | 登录页的 LDAP 复选框和说明在登录按钮前，同一行展示；真实认证、退出与强制改密流程可用 |

## 共享导航回归

| 编号 | 用户故事 | 验收与旅程 |
| --- | --- | --- |
| UI-US03 | 作为使用手机的值班人员，我要展开当前模块栏目，并用键盘返回导航入口，以便快速切换。 | 栏目展开时可以找到当前页面。Escape 收起。选中其他栏目后正文可继续操作，宽表支持横向滚动。对应 UI-UT13、UI-UT19。 |
| UI-US04 | 作为平台管理员，我要在同一套工作区完成集群范围切换、目录和审计操作，以便核对平台状态。 | 集群与命名空间共享已授权范围，现有 LDAP 验证、权限配置和操作审计可从各自入口完成。对应 UI-UT07、UI-UT10、UI-UT11、UI-UT15。 |
| UI-US05 | 作为拥有受限权限的知识库读者，我要能检索和阅读授权文档，以便借鉴已有故障处理方法。 | 可打开搜索结果与详情。治理入口随能力派生，服务端拒绝的请求展示受限状态。对应 UI-UT03、UI-UT09。 |
