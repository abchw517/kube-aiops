# 功能拆解

| 编号 | 功能 | 规则 |
| --- | --- | --- |
| F-01 | 诊断记录分页 | 按聚合后的实际集合切片，默认 5，支持 10、15 和 1–100 的整数 |
| F-02 | 诊断页状态 | 地址用 recentPage 和 recentPageSize，错误值回落，越界夹到最后可用页，改变范围回第一页 |
| F-03 | 诊断详情往返 | 详情链接携带返回查询，窗口切换更新详情返回地址 |
| F-04 | 知识检索与排序 | search 输入提交时保留其他条件，筛选切换清除旧游标，最近更新使用服务端全量排序 |
| F-05 | 知识结果摘要 | 文字高亮先转义，状态、团队与版本以实际文档元数据为准 |
| F-06 | 快速知识预览 | 打开时按所列版本请求；关闭取消请求，迟到的响应无法覆盖其他预览或新页面 |
| F-07 | 登录页装饰 | 背景不可交互，静态分辨率随视窗调整；离开登录外框停止监听 |
