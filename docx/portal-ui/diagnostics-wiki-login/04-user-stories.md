# 用户故事

| 用户 | 情境 | 可验收结果 |
| --- | --- | --- |
| 值班工程师 | 正在查看第一屏以外的诊断 | 点下一页看到第 6 条及之后的记录，无需离开总览 |
| 值班工程师 | 希望临时查看 7 条或调整过滤范围 | 自定义 7 生效；无效值有提示；改筛选后从第 1 页开始 |
| 故障负责人 | 打开详情后还要继续排查列表 | 返回时恢复原查询、页位置与每页条数 |
| 排障人员 | 用 Kubernetes 事件 Reason 搜索 | 可看到命中和适用范围，快速查看关键步骤并保留检索现场 |
| 知识维护人 | 要查看近期更新或待复核内容 | 最近更新跨页排序，文档复核状态和团队清晰可见 |
| LDAP 用户 | 从窄屏进入控制台 | 背景与卡片有清晰反差，LDAP 选项与文案同行，校验和登录反馈仍可读 |
