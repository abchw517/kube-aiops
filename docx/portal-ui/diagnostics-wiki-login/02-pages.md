# 页面拆解

| 页面 | 区块 | 交互 |
| --- | --- | --- |
| 诊断控制台 / 诊断总览 | 原有范围、指标、趋势、最近诊断表或卡片 | 保持首次发现时间排序、同源详情和原有下钻 |
| 最近诊断底栏 | 当前范围、总条数、前后页、每页条数 | 自定义行数可应用、取消或按 Esc 收起 |
| 运维知识库 / 知识检索 | 搜索框、常用词、筛选面板、已应用条件、结果列表 | 切换排序、清除单项、翻页、进入全文或打开快速预览 |
| 知识预览侧栏 | 标题、适用范围、团队和版本、检查与恢复、全文按钮 | 可键盘关闭，焦点回到触发控件；请求中、失败、授权或文档状态变化有反馈 |
| 知识全文 | 返回结果、当前或历史版本、正文、章节、反馈及关联诊断 | 返回恢复已应用查询与分页，历史版本可跳到当前版本 |
| 登录控制台 | 品牌顶栏、科技背景、用户名、密码、LDAP、登录及反馈 | 默认本地登录，LDAP 复选框同行，保留凭据校验与会话处理 |
