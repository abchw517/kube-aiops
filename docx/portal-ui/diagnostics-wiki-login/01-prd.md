# PRD

| 编号 | 优先级 | 需求 | 验收 |
| --- | --- | --- | --- |
| PR-01 | P0 | 最近诊断可查阅其他记录 | 初始 5 条，前后翻页，可切换 5、10、15 或自定义 1–100 |
| PR-02 | P0 | 分页与查询上下文一致 | 明示显示范围、总数和页码，页容量与筛选重置页码，详情返回恢复分页，趋势切换保留分页 |
| PR-03 | P0 | 知识检索结果便于扫读 | 按关键词、环境、业务线、资源及知识类型筛选，显示命中原因、适用范围、责任团队、版本及复核提醒 |
| PR-04 | P0 | 快速判断文档是否适用 | 可从结果快速预览或打开全文，返回保留查询，预览失败可重试 |
| PR-05 | P0 | 登录背景有柔和科技感 | 桌面呈现浅蓝紫渐变与静态装饰，窄屏登录卡和操作完整可见 |
| PR-06 | P0 | 保持权限和业务一致 | 知识预览核验文档版本和授权；本地与 LDAP 登录及会话过期反馈可用 |

产品目标是在诊断列表与进入知识全文前减少反复跳转。现网数据来自原有 API。原型中的固定演示数据只用于验收交互。
