# 测试用例

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-01 | 打开含 23 条记录的总览，翻到末页 | 首屏 1–5，末页 21–23，前后按钮按边界禁用 |
| TC-02 | 切换 10、15 和自定义 7；输入 0、101 或非整数 | 合法值生效并回第 1 页，无效值提示，取消保留原配置 |
| TC-03 | 过滤来源／级别、切换趋势窗口、打开详情再返回 | 改筛选回首页；趋势不改当前记录页；返回恢复页和大小 |
| TC-04 | 模拟覆盖不完整、空结果或页码过大 | 仅报告已获取总数；空结果提示；越界回到可用页 |
| TC-05 | 搜索含 HTML 语义字符或匹配词，切换筛选 | 文本按原样安全显示，可高亮命中，返回结果 count 与接口一致 |
| TC-06 | 改最近更新排序再翻页，随后变更筛选 | 先对完整授权集合排序，再分页，旧游标不用于新查询 |
| TC-07 | 打开预览、快速关闭、打开正文再返回 | 显示正确版本，取消请求不串页，焦点和检索状态可恢复 |
| TC-08 | 预览版本被撤回、越权或请求失败 | 不显示正文；无权限、已失效与可重试错误有对应提示 |
| TC-09 | 桌面及 390 px 窄屏访问未登录页 | 背景与输入明确分层、无水平溢出，LDAP 与文字在同一行 |
| TC-10 | 本地与 LDAP 登录、校验失败和会话过期 | 原有实际认证流程和消息正常，登录完成后卸载装饰 |
