# 全站 UI · 功能拆解

## UI-F01 导航

根据路由及用户能力展示模块、栏目、高亮和面包屑。旧地址、详情返回参数、刷新与前进后退继续可用。移动侧栏可从键盘展开，导航成功后关闭。注销及修改密码按现有身份规则显示。

## UI-F02 诊断总览

从真实故障数据生成关键指标、时间趋势、级别构成和最近故障。图表提供时间刻度、级别及数值明细，图表和列表使用同一范围。数据来源仅覆盖部分记录时说明统计范围。无数据展示空态，读取失败展示错误。保留故障详情、拓扑、AI 分析和诊断筛选。

## UI-F03 集群与命名空间

范围树仅包含权限允许的环境与集群，支持全部可见、按环境和按集群选择。范围搜索过滤树节点，表内搜索过滤当前结果。切换集群及命名空间视图时保持适用范围。命名空间来自已授权的服务端数据。维护、重新采集与归属编辑沿用现有接口。

## UI-F04 知识库

保留文本检索、适用范围、分页、知识详情和旧链接。详情保留章节及关联诊断。问答、草稿和治理按用户能力显示，直接访问仍由服务端授权。

## UI-F05 系统管理

用户、权限、审计和改密沿用业务规则。认证配置的两个折叠区可分别展开，保存互相独立。会话策略走 `/api/v1/admin/session-policy`，SQLite 默认 30 分钟，本地超管可设置 5 至 480 分钟的整数。成功后标题栏立即更新，新时长只用于之后签发的会话。LDAP 保留原有四阶段验证和启用流程。

## UI-F06 状态与可访问性

结果区分别显示加载、无匹配、服务错误及权限不足。保存失败保留有效草稿，保存期间防止重复提交。会话过期走原登录流程。交互有可见焦点、可读名称和当前状态，图表和状态标签保留文字信息。
