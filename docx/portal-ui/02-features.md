# 全站 UI · 功能拆解

## UI-F01 导航

根据路由及用户能力展示模块、栏目、高亮和面包屑。旧地址、详情返回参数、刷新与前进后退继续可用。移动侧栏展开后聚焦当前栏目或首个可用栏目。按 Escape 收起并将焦点还给按钮，导航后收起并将焦点移至正文。注销及修改密码按现有身份规则显示。

## UI-F02 诊断总览

从真实故障数据生成待确认、处理中、高风险（P1）、已恢复计数。指标标题可进入同范围的故障列表并补充对应状态或严重程度。当前筛选与指标维度冲突，或该指标暂不可用时，标题只显示文字。「查看全部」保留当前筛选。两个入口都从第一页查询。

范围摘要展示生效的条件，未选条件时显示「全部可见范围」。应用或清除筛选从第一页查询。图表与最近故障使用同一范围，部分覆盖标明统计范围，未知计数显示「暂不可用」，零计数显示「0 件」。趋势保留 UTC 日期，键盘可读具体计数。保留故障详情、拓扑、AI 分析和旧 Findings 筛选。

## UI-F03 集群与命名空间

资源管理的集群入口与标题统一显示「Kubernetes 集群管理」，沿用 `#/resources/clusters`。范围树仅包含权限允许的环境与集群，点击「全部集群」、环境名称或集群名称，分别查看全部可见、当前环境或单个集群的结果。范围搜索过滤树节点，表内搜索过滤当前结果。切换集群及命名空间视图时保持适用范围。命名空间来自已授权的服务端数据。维护、重新采集与归属编辑沿用现有接口。

## UI-F04 知识库

保留文本检索、适用范围、分页、知识详情和旧链接。详情保留章节及关联诊断。问答、草稿和治理按用户能力显示，直接访问仍由服务端授权。

## UI-F05 系统管理

用户、权限、审计和改密沿用业务规则。认证配置的两个折叠区可分别展开，保存互相独立。会话策略走 `/api/v1/admin/session-policy`，SQLite 默认 30 分钟，本地超管可设置 5 至 480 分钟的整数。成功后标题栏立即更新，新时长只用于之后签发的会话。LDAP 连接参数区展示 URL、搜索 DN、搜索密码、基础 DN 和明文连接选项。点击明文选项的复选框或标签文字均可切换。测试区展示目录连接、搜索账号绑定、员工查询、员工认证。修改配置后需重新测试。

侧栏「权限管理」进入角色草稿。可逐项勾选，或按工具集合及当前筛选批量选择。被筛选隐藏的选择保留。不同范围类型分次加入清单，确认后提交，角色授权作用于直接关联或通过用户组继承该角色的账号。

## UI-F06 状态与可访问性

结果区分别显示加载、无匹配、服务错误及权限不足。保存失败保留有效草稿，保存期间防止重复提交。会话过期走原登录流程。交互有可见焦点、可读名称和当前状态，图表和状态标签保留文字信息。
