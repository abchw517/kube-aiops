- 资源夹具包含研发实例 `dev-a`、测试实例 `test-a`、生产实例 `prod-a`。包含有效、缺失、多业务归属及同名命名空间。两个实例用相同诊断 ID 验证隔离。

## LLM Wiki 知识闭环与演进

这一节保留知识闭环的分期设计与历史验收。生产检索只引用生效的已授权知识。诊断复核先保存，知识发布走候选草稿、审核和独立发布。尚未交付的自动增强、索引与同步规则按规划评审。

运维知识库下一轮迭代以 [v1.0 评审稿及其拆解](05-unit-test-cases.md#文档治理与诊断联动) 为评审依据。本文件保留 Phase 3 的设计及已交付接口背景。

诊断详情内的复核和独立发布见 [DC-UT04](../diagnosis-console/05-unit-test-cases.md#dc-ut04)。含队列、索引和同步的用例用于 Wiki 后续验收。以 [需求文档](00-prd.md#llm-wiki-知识闭环与演进) 为准。表内 R 编号省略 WK 前缀。

### 测试数据

- 测试环境「运维」业务的集群实例 A，命名空间 `ops-demo`，Finding F1 为镜像拉取失败。K8sGPT 初判为镜像不可用，现场事件显示镜像仓库返回 403。模拟 Wiki 提供同范围已确认案例 K1 v1，结论为拉取凭据过期。
- 在生产环境、其他业务、另一集群实例及另一命名空间各放置相同故障签名和不同的可识别标记，用来检测越权。另提供一个只读用户、一个复核人员及一个仅授权实例 A 的知识发布人员。
- 模拟 Wiki 记录请求及版本，并可切换为空结果、超时、跨范围返回、写入后断连、延迟索引和不可用。模型夹具记录输入并能返回非法引用。每个用例使用可重置的 SQLite 数据库，升级用例使用旧版本库。

### 功能、健壮性与权限

| 用例 | 层级 / 需求 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| WK-C01 初步诊断 | API / R01 | 导入 Result 后立即打开 F1，延迟 Wiki 响应。 | 首次响应可读初步诊断及生成状态，Result 与初步文本保持原样。 |
| WK-C02 增强诊断 | 集成 / R02 | 访问 F1，Wiki 返回 K1 v1，现场事件返回 403。 | 调用顺序为 Wiki 查询在模型调用之前，模型收到初步诊断、现场事件和 K1 v1，页面区分证据及引用。 |
| WK-C03 降级 | 集成 / R03、R10、R11 | 分别模拟无匹配、超时、Wiki 初始化失败和模型错误。 | 有明确状态，初步诊断仍可读取。Wiki 不可用时可用现场证据仍参与分析，模型失败时展示初步诊断。 |
| WK-C04 重复读取与重新分析 | 集成 / R02、R03、R10 | 并发读取同指纹 Finding，随后授权重新分析。 | 并发请求复用一次生成。重新分析执行一轮新检索，已有确认结论未被覆盖。 |
| WK-C05 复核和补充观察 | 浏览器 / R04 | 先一键复核，再输入观察重新复核，编辑后保存。 | 两次复核在页面显示判断与来源，只有保存写入诊断版本。Wiki 无写入。 |
| WK-C06 权限与归属 | API / R04、R05、R08 | 复核人员无 Wiki 发布权限，或发布人员用另一 Finding 的预览编号提交。 | 请求拒绝，无知识条目或诊断版本变更。 |
| WK-C07 确认与索引 | 浏览器 / R05、R06 | 预览后确认 F1，Wiki 写入成功后暂缓索引。 | 返回 202、结论版本和任务 ID。已确认结论可读，索引就绪前显示待同步，就绪后展示知识编号和版本。 |
| WK-C08 重复发布与版本冲突 | 集成 / R05 | 重复提交同一已保存版本的预览编号，再保存新版本并尝试用旧编号发布。 | 同一版本重复提交复用知识条目；旧版本返回 409。 |
| WK-C09 事务回滚 | 集成 / R05 | 注入 outbox 插入失败，再解除故障重试。 | 首次无新确认结论、快照或任务。重试完整保存三者。 |
| WK-C10 发布响应丢失与重启 | 集成 / R06、R10 | Wiki 收到 PUT 后断开连接，工作进程重启后恢复任务。 | 后续使用同一编号、版本和哈希重试。索引中只形成一个生效版本。 |
| WK-C11 重试上限和人工恢复 | 集成 / R06 | Wiki 持续失败直至重试上限，恢复后由授权人员重新排队。 | 退避符合配置，结论可读。页面先显示待处理，重新排队后最终显示已同步。确认及重试事件可审计。 |
| WK-C12 订正、乱序和撤回 | 集成 / R07 | 先同步 v1，再确认 v2。延迟一条 v1 重试，随后撤回该知识。 | 两版编号相同。v1 重试不能覆盖 v2。撤回后搜索无该条目，结论历史和审计保留。 |
| WK-C13 作用域隔离 | API / R08 | 模拟返回四种越权标记，依次切换实例和命名空间，再检查缓存、模型输入及页面。 | 越权内容被过滤，不经缓存、模型或页面返回，不影响同范围候选。 |
| WK-C14 脱敏和引用校验 | 集成 / R09 | 对话和证据中加入测试凭据，模型返回候选之外的引用编号或版本。 | 敏感标记不出现在 Wiki、模型输入或日志。错误引用不展示为证据，Wiki 条目无对话全文。 |
| WK-C15 迁移和契约 | CI / R11 | 对旧 SQLite 库执行升级，验证现有复核历史，运行 API 契约与客户端一致性检查。 | 既有记录仍可查询，契约与生成客户端一致，常规 Finding 详情和复核回归通过。 |
| WK-C16 真实闭环 | 集群端到端 / R02、R04、R05、R06、R07、R11 | 从空持久卷部署，在测试集群产生 F1，完成对话并确认发布。生成同范围相似故障 F2，随后订正并撤回 F1 知识。 | F2 的增强说明引用可检索的 F1 知识版本。新分析反映订正和撤回结果。保留脱敏请求、任务状态及审计作为验收证据。 |
| WK-C17 空库自动创建 | 集群端到端 / R12 | 使用空 PVC 启动 Portal API，检查迁移和 Wiki 路由，再提交首条知识并重启。 | 程序自动创建表和索引，首次查询为空。首条发布可检索，重启后记录与索引保留，迁移可重复执行。 |
