# 运维知识库 · 测试用例

[PRD v1.0](00-prd.md) · [开发任务](04-development-tasks.md)

## 夹具与执行方法

- 资源夹具包含研发实例 `dev-a`、测试实例 `test-a`、生产实例 `prod-a`。包含有效、缺失、多业务归属及同名命名空间。两个实例用相同诊断 ID 验证隔离。
- 用户夹具包含系统管理员 A/B、显式获得单范围 Wiki 读权限的既有策略账号、无 Wiki 权限的 LDAP 账号及访客。生产发布用双管理员。范围及权限失效使用可控开关。
- 知识夹具包含已发布、草稿、待复核、撤回、旧版和失权条目；包含已获共享批准手册与仅生产可读案例。模型夹具可返回超时、非法引用及延迟。导入夹具用脱敏 SQLite、相同远端页与哈希、完整及中断分页。
- 单测验证排序、模板、范围解析、状态迁移和版本选择；集成验证 API、事务、审计及权限；浏览器验证跨页流程、状态和错误恢复。所有表为开工前用例，执行后在实现 PR 记录结果。
