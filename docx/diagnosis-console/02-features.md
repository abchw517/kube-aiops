覆盖诊断总览、故障事件、原有诊断结果、证据与复核、拓扑、AI 分析和诊断策略。总览采用聚合后的全量统计与最近诊断分页，数据源配置归[资源管理](../resource-management/design.md)。

## 最近诊断分页

| 编号 | 功能 | 规则 |
| --- | --- | --- |
| DWL-F-01 | 诊断记录分页 | 按聚合后的实际集合切片，默认 5，支持 10、15 和 1–100 的整数 |
| DWL-F-02 | 诊断页状态 | 地址用 recentPage 和 recentPageSize，错误值回落，越界夹到最后可用页，改变范围回第一页 |
| DWL-F-03 | 诊断详情往返 | 详情链接携带返回查询，窗口切换更新详情返回地址 |

## 统一诊断总览

| 功能 | 规则 |
| --- | --- |
| F1 聚合 | 并发加载授权列表，按实例和 Finding ID 归并，再应用统一级别筛选。 |
| F2 摘要 | 共用同一记录集。趋势切片使用 UTC+8 的 7、14 或 30 天，局部重绘，无新增时显示紧凑状态。最近记录按首次发现倒序分页，默认每页五条。 |
| F3 兼容 | 保留原列表路由及返回链，老数据源地址保留查询参数跳转。 |
| F4 权限与失败 | 既有接口裁决与脱敏；覆盖不足明确提示；会话失效遵循现有入口。 |
| F5 工作台布局 | 趋势与分布共用一张分析卡，位于最近诊断之前。窄屏两列指标，最近记录使用卡片。 |
| F6 覆盖提示 | 完整覆盖且趋势窗口为零时提示无新增。失败、受限、部分覆盖分别呈现，缺少时间不推断为窗口前。 |
| F7 日期读数 | 默认选中最新有记录日。点击柱体或用左右键、Home、End 切日，显示该日与各来源明细。 |
| F8 级别分布 | 环图分段按当前筛选范围百分比计算，显示数量和一位小数的占比。严重度明细和指标卡共用全局级别参数。 |

## 诊断结果与详情

[PRD v1.2](00-prd.md#诊断结果与详情) · [页面拆解](01-pages.md#诊断结果与详情) · [HTML 原型](finding-review.html)

### DC-F01

**环境和实例范围** · 页面 [DC-P01](01-pages.md#dc-p01)

进入没有范围参数的列表或选择「全部环境（ALL）」时，以当前账号可访问的全部实例为候选。指定环境按当前环境归属缩小候选，指定实例限定到该实例。保留显式实例直链，显式环境从 URL 恢复。变更父级范围时清理失效下游选择和游标。沿用现有「清除筛选」的用途，清除结果条件并保留显式范围。失效范围按失败或空态规则处理，不扩大范围。

对应 [DC-US01](03-user-stories.md#dc-us01)。

### DC-F02

**同范围汇总、列表和详情** · 页面 [DC-P01](01-pages.md#dc-p01)、[DC-P02](01-pages.md#dc-p02)

使用现有授权的诊断数据计算总数、各级别数和分布。列表与汇总使用相同的范围及结果筛选；统计范围跨整页分页。分页保留筛选，结果排序在时间相同的情况下仍可区分实例及 ID。记录显示真实实例，详情请求恢复实例上下文。读取失败时复用页面错误状态，不静默丢弃失败实例。

对应 [DC-US02](03-user-stories.md#dc-us02)。

### DC-F03

**严重级别说明** · 页面 [DC-P01](01-pages.md#dc-p01)

说明入口贴近各级别的标签，提供可读名称、可见焦点和非颜色线索。鼠标悬停、键盘聚焦时可查看，点按可保持显示，支持通过 Escape 或再次点按关闭。说明文字以实际影响和排查紧迫度为主。现有级别数据、颜色辅助及过滤值沿用。

对应 [DC-US03](03-user-stories.md#dc-us03)。

### DC-F04

**证据复核与独立发布** · 页面 [DC-P02](01-pages.md#dc-p02)

一键用当前诊断范围内的证据生成结构化复核结果。引用可回查、历史知识单独显示。允许补充观察和重试。保存结论创建诊断版本，Wiki 发布由有权人员预览并单独确认。

对应 [DC-US04](03-user-stories.md#dc-us04)。

### DC-F05

**证据折叠与重新复核** · 页面 [DC-P02](01-pages.md#dc-p02) · 故事 [DC-US05](03-user-stories.md#dc-us05)

| 能力 | 规则 |
| --- | --- |
| 展开和收起 | 四个来源使用同样的标题和折叠控件，包括零结果、部分可用、暂不可用和禁用。只切换对应来源。 |
| 引用定位 | 用来源和信号 ID 匹配证据。打开对应折叠项，定位记录。记录缺失时显示来源状态并聚焦标题，来源未就绪或不可读时定位证据区标题。 |
| 重新复核 | 提交点击当时的补充观察，使用原 `action=assess`。同一输入正在请求时避免重复提交。新输入显式提交后取消旧请求。 |
| 超时反馈 | 模型调用默认 90 秒，允许配置 5–120 秒。API 等待期限、上游 HTTP 超时和外层 504 显示不同提示。保留观察、已有结果和复核版本。 |
| 资源授权 | 证据使用 `diagnosis.evidence.read`。复核发起、历史、保存各自沿用原权限。展开操作不发送 API 请求。 |
