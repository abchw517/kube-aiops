覆盖诊断总览、故障事件、原有诊断结果、证据与复核、拓扑、AI 分析和诊断策略。总览采用聚合后的全量统计与最近诊断分页，数据源配置归[资源管理](../resource-management/design.md)。

## 最近诊断分页

| 页面 | 区块 | 交互 |
| --- | --- | --- |
| 诊断控制台 / 诊断总览 | 原有范围、指标、趋势、最近诊断表或卡片 | 保持首次发现时间排序、同源详情和原有下钻 |
| 最近诊断底栏 | 当前范围、总条数、前后页、每页条数 | 自定义行数可应用、取消或按 Esc 收起 |

## 统一诊断总览

| 页面 | 区域与交互 |
| --- | --- |
| 诊断总览 | 紧凑筛选和最近诊断捷径 → 四张指标卡 → 左侧趋势和右侧严重度分布组成的分析卡 → 最近诊断分页与完整列表入口。 |
| 故障详情 | 展示故障真实状态，返回原总览时恢复完整查询条件。 |
| 原有诊断详情／结果 | 通过实例 ID 定位结果并保留回链，旧侧栏继续进入完整列表、筛选和分页。 |
| 数据源管理 | 列于资源管理的平台目录，沿用配置、编辑、连通测试、同步、资产和启停。 |

内容宽度不超过约 760 px 时，分布移到趋势下方。30 天允许绘图区内部滚动，两个坐标轴与日读数仍可用。窄屏最近记录切换为卡片。

## 诊断结果与详情

[PRD v1.2](00-prd.md#诊断结果与详情) · [模块开发规范](../development-standard.md) · [HTML 原型](finding-review.html)

### DC-P01

**诊断列表** · 入口「诊断控制台」或 `#/findings`

面向拥有诊断读取权限的用户。集群范围区先展示「环境」和「全部环境（ALL）」默认值，其余范围条件按当前可见数据联动。保留命名空间、严重级别、资源类型、清除筛选和分页。汇总区显示总数、严重、警告和信息，级别标签旁提供说明。跨实例列表显示实例名，并呈现当前范围下的资源类型及命名空间分布。

请求期间显示加载，授权范围为空时复用无权限状态，能查询但没有匹配结果时显示空态。认证失败进入登录，权限不足和加载失败使用现有反馈与重试方式。

关联功能 [DC-F01](02-features.md#dc-f01)、[DC-F02](02-features.md#dc-f02)、[DC-F03](02-features.md#dc-f03)。

### DC-P02

**诊断详情** · 入口列表问题链接或既有详情直链

使用记录所属实例及诊断 ID 定位。按接口权限显示详情、关联证据和 AI 复核。跨实例同名记录独立定位。资源不可见、已移除或请求失败时沿用各自现有状态。

| 区域 | 控件与内容 | 状态转换 |
| --- | --- | --- |
| 诊断说明 | 原始说明、已保存版本、AI 复核入口 | 进入页面不调用模型，点击后开始首次复核。原始说明一直可读。 |
| AI 复核 | 当前判断、证据依据、待验证项、下一步、补充观察和保存 | 提交观察后显示复核中。超时保留观察和已有结果，并恢复「重新复核」。 |
| 关联证据 | 时间窗口、四个工具标题，分别显示条数和状态 | 默认收起，点击标题独立展开。零条展开后显示对应说明。整区失败时保留原诊断和现有重试入口。 |
| 引用跳转 | AI 结果中的可定位引用 | 打开目标来源并聚焦证据。若当前来源缺少对应记录，聚焦该来源标题。证据区尚未就绪或不可读取时聚焦区块标题。 |
| 关联知识 | 已保存结论的知识沉淀入口 | 根据现有权限进入独立提交与发布流程。 |

HTML 原型打开后，从列表选择「Pod 镜像拉取失败」。可依次点击四个工具，点击「AI 复核」查看引用，再补充 `集群使用的是 containerd`。原型模拟首次补充提交超时，重试后展示更新结果。

关联功能 [DC-F02](02-features.md#dc-f02)、[DC-F04](02-features.md#dc-f04)、[DC-F05](02-features.md#dc-f05)。

## 故障事件、拓扑、AI 分析与策略

这里保留 V2 的分期范围、故障处置和相关验收。总览口径与入口以本文件上方的统一诊断总览为准。

[PRD](00-prd.md#故障事件拓扑ai-分析与策略) · [功能](02-features.md#故障事件拓扑ai-分析与策略)

| 编号 | 页面 | 交互及数据 | 权限及异常状态 |
| --- | --- | --- | --- |
| DC-P01 | 诊断总览 | 环境、业务、集群筛选，严重级别汇总、最近异常及资源分布，点进事件或详情。P1 增加活跃故障、平台/来源、趋势与待关注列表。 | 现有汇总、列表和发现权限。单来源读失败提示重试。授权范围内无记录时显示零值及空态。 |
| DC-P02 | 故障事件 | P0 展示 Finding 信号，按环境、业务、集群、命名空间、严重级别、类型和问题文本筛选。P1 加入事件状态、P1/P2/P3、待确认和处理中快捷分组、人工创建。 | 浏览与写入独立授权。游标分页，切换筛选回到第一页。空、403、离线和查询失败分别处理。 |
| DC-P03 | 故障详情 | 详情头展示来源、资源和时间。关联证据按工具分组，供展开、复制、引用定位。后续增加时间线、处理建议、影响面入口与更新状态。 | 详情、证据查询及写入分别授权。失败区独立重试。引用冻结快照过期时显示已过期。 |
| DC-P04 | AI 根因分析 | 显示任务阶段、运行状态、候选根因、可信度、待验证项、引用、版本历史。允许补充观察、重新分析、取消任务。 | 查看历史、启动与保存分别授权。超时、取消和失败保留草稿及上一版可读结果。 |
| DC-P05 | 关联拓扑 | 基于当前故障浏览上下游。点选节点展示资源归属、观察、联系置信度和证据。可从节点进入授权详情。 | 缺少数据时显示覆盖范围。仅返回可见节点与两端均可见的边。候选关系标记为推断。 |
| DC-P06 | 数据源管理 | 数据源列表、类型、范围、健康与最后同步时间。配置新增、编辑、启停及服务端连接测试。 | 读、编辑、启停、连接测试分别授权。测试返回分类状态，失败结果只包含安全的错误摘要。 |
| DC-P07 | 诊断策略 | 策略列表、触发来源、范围、模板与自动触发。新增和编辑支持配置验证及上线路径。 | 策略写入由已有权限体系授权。并发版本冲突保留草稿。策略禁用后停止新触发。 |
