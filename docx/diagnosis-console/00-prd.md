# kube-aiops「诊断控制台」PRD

- **版本** v1.2
- **更新日期** 2026-11-20
- **目标用户** 使用诊断控制台查看 Kubernetes 诊断结果的 OPS 与授权访客

## 目标

进入诊断控制台时，用户先看到当前账号有权查看的所有环境的诊断结果，并能缩小到指定环境或集群实例。用户可在原位置了解各严重级别的含义，辅助判断排查优先级。

## 环境范围

- 无范围参数的诊断列表默认选择「全部环境（ALL）」，查询当前账号能访问的实例，并使用现有诊断列表和汇总权限过滤结果。未授权实例及命名空间不能进入选项、列表、汇总、副统计或详情。
- 选择一个环境时查询该环境下符合当前条件的授权实例。环境、业务、集群名称和实例的选项按上游范围联动，父级切换时清理不再适用的下游选择。切换环境后只要未指定更窄范围，列表仍涵盖该环境内全部符合条件的实例。
- 显式实例参数如 `#/findings?cluster=local` 指向该实例，保持原单实例语义。显式环境直链需能刷新复现。未知或无权访问的范围不回退到其他环境或实例。既有本地与远程诊断详情直链兼容。
- 范围外的结果不可见。同一范围和结果筛选条件下，总数、严重级别、分类分布及列表使用一致的数据口径。每条结果保留实例归属，打开时进入该实例的诊断详情。
- 列表分页按聚合结果排序，沿用稳定顺序。切换筛选时从首页开始。来源不可访问或数据获取失败时，复用现有登录、无权或可重试错误状态。若无法取得完整范围的数据，禁止以无提示的部分数据冒充完整总量。授权范围内无匹配结果时显示空态。

## 严重级别说明

说明放在诊断汇总的「严重、警告、信息」旁，与对应术语关联。鼠标悬停、键盘聚焦和触屏点按均可查看，支持明确关闭或按 Escape 退出，说明不依赖颜色。

| 级别 | 面向用户的说明 |
| --- | --- |
| 严重 | 关键服务已中断或主要功能受明显影响，应优先排查。例如关键工作负载无可用副本。 |
| 警告 | 服务仍可提供，但出现降级或存在故障风险，应安排排查。例如副本数下降或工作负载反复重启。 |
| 信息 | 可关注的现象或优化建议，暂未观察到直接服务影响。例如资源配置优化建议。 |

示例用于解释常见影响，具体结果使用接口返回的级别，保留 `critical`、`warning` 和 `info` 的既有映射。诊断详情内的 AI 复核按下述流程提供。

## 本轮范围

在现有诊断详情中收起四种来源的证据明细，减少首屏滚动。补充观察后重新复核沿用原入口，延长模型等待预算并提供按失败来源区分的重试提示。列表、环境筛选、诊断原文、复核历史及知识发布沿用现有流程。

## 诊断详情内的关联证据

| 初始状态 | 操作 | 结果 |
| --- | --- | --- |
| Kubernetes 事件、Prometheus、VictoriaLogs、Alertmanager 全部收起 | 点击任意标题，或聚焦后通过键盘展开 | 仅切换该来源，标题始终显示工具名称、当前状态和证据条数。 |
| 来源有结果 | 展开 | 展示原有明细、时间、数值及次数。 |
| 来源无结果 | 展开 | 根据可用、部分可用、暂不可用或已禁用显示提示。标题条数为 0。 |
| 点击 AI 证据引用 | 导航到证据 | 自动打开对应来源并聚焦该条记录。引用不在当前列表时定位来源标题，整个证据区不可读或未就绪时定位区块标题。K8sGPT 引用定位原始说明。 |

## 诊断详情内的证据复核

- 值班人员从「诊断说明」点击「AI 复核」，在卡片内展开复核区。原始诊断、故障信息和关联证据可同时查看。关联证据的每个来源均默认折叠并可独立展开。无结果、不可用或已禁用的来源展开后显示状态说明。进入详情页不会自动调用模型。首次点击直接开始复核，无需先发送消息。
- 结果包含「当前判断」「证据依据」「待验证项」「下一步」。状态为证据支持、证据不足或证据冲突。仅历史案例、人工陈述或 K8sGPT 原始诊断无法单独证明当前状态。引用可从结果定位到平台记录，显示来源及记录时间。历史观察标记为历史，并提示核对当前状态。Wiki 引用单独展示。
- 复核期间可查看已有证据。展示数据源可用、部分可用、不可用、已禁用或超时未取得数据的状态。模型失败时保留原始诊断、现场证据和已填写的观察，支持就地重试。用户可在等待复核期间填写人工观察或问题。提交新的观察时立即反馈，并用本次提交替换原请求。未提交的补充保留在原处。人工观察与机器证据分别处理。
- 可编辑并保存复核结论。已保存结论附版本，刷新可见；原始诊断继续展示。并发保存返回冲突，重新载入版本后由用户确认。普通诊断读者可查看已保存结论，发起复核、读取历史和保存分别沿用现有资源范围授权。
- 取得 Wiki 发布权限且诊断有命名空间时，可对已经保存的结论生成脱敏预览并单独确认发布。发布范围从当前诊断派生，重复发布相同内容复用现有知识条目。发布失败可重试并保留已保存结论。模型输出只提供验证建议，平台不自动执行修复。

### 超时与验收条件

- 超时保留正在编辑的补充观察、上一轮判断和已保存结论。按钮恢复可用，使用同一观察可再次提交。模型复核结果由用户确认保存。
- 区分 API 等待模型超时、模型服务以 HTTP 状态明确返回超时和外层网关超时。部署基线详见[部署说明](../install-deployment.md)。
- 原有证据读取与复核权限分别生效。证据折叠、展开和引用导航只操控当前详情已获授权的数据。
