# 诊断控制台 · 测试用例

[PRD v1.0](00-prd.md) · [开发任务](04-development-tasks.md) · [HTML 原型](prototype.html)

测试夹具包含生产实例 `prod-east`、测试实例 `test-k8s`、无权实例 `prod-internal`。前两者可读，并各自包含 namespace 权限边界。另准备相同诊断 ID 和发现时间、实例不同的两条记录，以及可注入读取错误的诊断源。浏览器使用同样语义的模拟数据。

## DC-UT01

**默认范围与筛选联动** · [DC-T01](04-development-tasks.md#dc-t01)

| 用例 | 操作 | 断言 |
| --- | --- | --- |
| DC-UT01-01 | 无筛选 URL 打开诊断列表 | 环境为「全部环境（ALL）」，API 请求聚合，显示生产和测试的有权实例。 |
| DC-UT01-02 | 选生产，选业务、集群名称或实例后切回测试 | 候选按可见范围缩小，失效子级和旧游标清除，查询从第一页开始。 |
| DC-UT01-03 | 直接打开环境 URL、旧 `cluster=local` 实例 URL，刷新并后退 | 范围可复现，具体实例不被扩为 ALL，旧实例请求和详情链接可用。 |
| DC-UT01-04 | 直接以不带实例的请求调用现有 API | 保持既有 `local` 行为。 |
| DC-UT01-05 | 聚合请求含无权实例、无权环境和无权命名空间 | 选项、列表与汇总没有无权数据。显式未知或被拒绝范围不会返回其它范围结果。 |
| DC-UT01-06 | 快速切换环境并让旧响应最后返回 | 可见范围、结果和总数维持当前选择。 |

## DC-UT02

**一致统计、跨实例分页和详情** · [DC-T02](04-development-tasks.md#dc-t02)

| 用例 | 操作 | 断言 |
| --- | --- | --- |
| DC-UT02-01 | 查询 ALL，随后限定环境、严重级别、命名空间及类型 | 列表、总数、级别统计和资源分布均反映相同条件。清除结果筛选保留环境范围。 |
| DC-UT02-02 | 让两条同时间同 ID、实例不同的记录位于分页边界 | 翻页完整遍历两条记录且各出现一次，计数总量跨页稳定，游标与筛选结果一致。 |
| DC-UT02-03 | 点击分别属于两个实例的同 ID 问题链接 | 打开对应实例详情，返回列表可恢复范围。原详情 URL 仍可打开。 |
| DC-UT02-04 | 授权范围存在但无符合项 | 显示零计数和空态；切换到有数据的范围后正常显示。 |
| DC-UT02-05 | 让一个授权来源返回读取错误 | 页面显示可重试错误，缺失数据未伪装成完整汇总；恢复后可正常查询。 |

## DC-UT03

**级别说明与可访问性** · [DC-T03](04-development-tasks.md#dc-t03)

| 用例 | 操作 | 断言 |
| --- | --- | --- |
| DC-UT03-01 | 分别悬停严重、警告、信息 | 各自显示 PRD 对应的影响范围和示例，鼠标可移入说明阅读。 |
| DC-UT03-02 | Tab 移到术语，按 Escape | 同一术语的说明可见，Escape 关闭且焦点保留，继续 Tab 能移到下个控件。 |
| DC-UT03-03 | 在移动视口中点按标签，再次点按 | 可展开或关闭，说明不溢出视口，能在下一操作前读完。 |
| DC-UT03-04 | 查看三个说明后对照级别筛选值和计数 | 原 `critical`、`warning`、`info` 映射及列表结果、URL 保持不变。 |
