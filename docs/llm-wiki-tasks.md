# LLM Wiki 诊断闭环任务拆分

需求编号见 [需求文档](llm-wiki-requirements.md)，测试编号见 [测试用例](llm-wiki-test-cases.md)。P0 为首期闭环开发，P1 为开放生产发布前的验收工作。依赖就绪的任务可并行。表内 R、T 编号省略 WK 前缀。

| 任务 | 优先级 | 依赖 | 工作内容与完成条件 | 需求 |
| --- | --- | --- | --- | --- |
| WK-T01 契约与夹具 | P0 | 无 | 定义进程内 Wiki 查询、写入与索引状态接口，补 Portal OpenAPI 和生成客户端。提供故障、知识、模型和模块故障注入夹具。接口校验通过。 | R01–R19 |
| WK-T02 内嵌 Wiki 初始化与查询 | P0 | T01 | 新增 SQLite 知识条目和索引迁移、检索及版本查询，接入资源授权。验证空库启动、升级重启和迁移失败。 | R02、R03、R08、R09、R10、R12 |
| WK-T03 增强诊断 | P0 | T02 | 复用 Engine 模型及关联证据，按 Finding 指纹生成并缓存增强说明，校验引用和降级状态。详情按字段返回各类说明。 | R01、R02、R03、R09、R10 |
| WK-T04 对话和草稿 | P0 | T03、PR #73 的对话能力 | 绑定基线版本，提交完整对话生成草稿。提供预览及编辑，模拟模型覆盖一轮、多轮及并发基线变化。 | R04、R08、R09 |
| WK-T05 确认与 SQLite 迁移 | P0 | T01、T04 | 增加快照、确认元数据及 outbox 表。复用现有复核历史，在同一事务检查版本和归属并保存结论、快照、任务。验证从旧库迁移、失败回滚及幂等。 | R05、R07、R08、R10、R11 |
| WK-T06 同步工作进程 | P0 | T02、T05 | 实现任务租约、稳定编号、幂等写入、索引轮询、退避及重试。验证响应丢失、并发领取、版本乱序及重启恢复。 | R06、R07、R10 |
| WK-T07 Portal 展示与操作 | P0 | T03、T04、T05、T06 | 展示初步诊断、增强说明及引用、已确认结论和任务状态。提供确认、重试入口和权限反馈，浏览器覆盖完整路径。 | R01–R08 |
| WK-T08 订正、撤回与部署 | P0 | T06 | 执行订正和受审计撤回，校验索引失效。补 Wiki 初始化、PVC 备份恢复、迁移及回滚文档。 | R07、R08、R10、R11 |
| WK-T09 发布验收 | P1 | T07、T08、T10、T11、T13、T14 | 运行回归和隔离测试，在内嵌 Wiki 与测试集群实测一次完整闭环并记录检索、发布、索引和审计结果。 | R01–R19 |
| WK-T10 文档列表与权限 | P0 | T01、T02 | 新增类型字段和迁移、组合筛选、授权分页和详情引用。在 Portal 增加同级导航入口及列表页，覆盖空库和权限隔离。 | R13、R15 |
| WK-T11 AI 知识问答 | P0 | T02、T10 | 开发问答 API 与默认展开的对话框，复用 Wiki 检索和模型连接，实现追问、引用校验、权限重验和缺证据提示。浏览器验证关闭重开及切换筛选。 | R14、R15 |
| WK-T12 文档解析和转换 | P0 | T01、T02 | 建立 Markdown、纯文本、DOCX 解析和统一转换，校验正文、元数据、内容限制与来源。实现任务状态及哈希防重。 | R16、R17、R19 |
| WK-T13 手工录入和上传 | P0 | T10、T12 | 实现录入页、批量导入、逐文件预览与确认发布。验证权限、失败反馈及索引。 | R16、R17、R19 |
| WK-T14 远端目录同步 | P0 | T06、T12 | 实现自建 Wiki URL 目录连接器，覆盖只读认证、连接预览、目录分页、子目录和正文读取。接入手动与定时增量同步，验证目录归属、授权拒绝及删除状态。 | R17–R19 |

阶段验收顺序为只读检索及增强、对话确认与发布、真实集群复用。验收从空持久卷开始，使用项目本身启动 Wiki 功能。
